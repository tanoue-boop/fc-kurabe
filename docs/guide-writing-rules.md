# 開業ガイド記事の書き方（フランチャイズくらべ）

## 置き場所と仕組み
- 記事は content/guide/<slug>.md（frontmatter: title, description, lead, photo, minor, major, updated, order）。
- photo は public/img/gyoshu/<minor>.jpg（差分 -2, -3 があれば使ってよい）。
- 本文中に次の目印を1行で書くと、サイトの本部データから自動で差し込まれる（金額は data/brands.json の最新値）。
  - [[table slugs=a,b,c]] / [[table minor=xxx]] / [[table tag=xxx fund=under-100]] … 比較表
  - [[brands minor=xxx]] / [[brands slugs=a,b]] … 本部カード（資料請求ボタンにつながる）
- 「出典：」で始まる段落は小さい出典表示になる。
- 記事を足すと /guide/ 一覧・業種ページ・本部ページ・サイトマップに自動で載る。

## 内容のルール（必ず守る）
1. 事実・数字はすべて出典付き。公的機関（国税庁・厚労省・消費者庁・経産省・中小機構J-Net21・日本政策金融公庫など）か、各社の公式ページを優先。出典が取れない一般論・推測は書かない（削る）。
2. WebFetchで数字を取るときは「原文の表記のまま引用して」と指示する（要約で数値が言い換わるため）。重要な数値は2回確認する。
3. 本部の金額は data/brands.json の値を使い、本文に書くときは税区分も書く。source_type が「A8案件情報のみ（数値未確認）」「媒体」の本部は、金額を本文に書かず、カード・表にも入れない。
4. 当サイトのデータから言えること（掲載本部の開業資金の幅、ロイヤリティの形の内訳など）を必ず1つ以上入れる。これが競合記事との違い。
5. 検索上位5〜8記事の見出し構成を調べ、共通して扱う論点は押さえつつ、抜けている論点を1つ以上入れる。
6. 自然な日本語。誇大表現・No.1表現・「おすすめ順」は使わない（根拠のない順位付けはしない）。体験したような書き方もしない。
7. 構成の型：結論（要点3つ）→ 需要・市場 → 資格・届出 → 開業資金（[[table]]）→ 毎月の費用・ロイヤリティ → 個人とFCの比較 → 本部カード（[[brands]]）→ 本部を選ぶときの確認点。業種に合わせて変えてよい。
8. 本文中で特定の本部を「おすすめ」しない。

## 公開の手順
1. npm run build が通ることを確認（失敗したら直す）。
2. 画面を確認（next start → scripts のスクショ or curl でHTMLに見出し・表があるか）。
3. main に push → Vercel の自動デプロイ完了を gh api repos/tanoue-boop/fc-kurabe/commits/<sha>/statuses で確認 → 本番URLが200を返すか確認。
4. content/guide/_queue.md を更新し、docs/guide-log.md に「日付・slug・狙いKW・主な出典」を1行追記して一緒にコミット。
