結婚相談所は、中小機構のJ-Net21が開業タイプとして「副業型」「専業型」「法人型」を挙げているように、始め方の幅が広い業種です。一方で、契約のルールが法律で細かく決まっているのが特徴です。この記事では、開業前に押さえたい「資格と届出」「法律のルール」「連盟の選び方とお金」を、公的機関と各社の公式情報で整理します。

## 結論：結婚相談所開業の要点

- **開業に必要な資格・許認可はありません。** 個人なら税務署への開業届が基本です。
- **ただし特定商取引法の「特定継続的役務提供」に当たります。** 期間2か月超・金額5万円超の契約では、書面の交付・クーリング・オフ・中途解約のルールを守る必要があります。
- **多くの相談所は「連盟」に加盟して、会員を紹介し合います。** 加盟費用は連盟によって大きく違い、IBJは個人で加盟金200万円（税抜）、TMSは加盟金85万円（税別）と公表しています。

## 結婚相談所の需要

厚生労働省の人口動態統計によると、令和7年の婚姻件数は489,158組で、前年より4,066組増えました。

出典：[厚生労働省「令和7年 人口動態統計（確定数）の概況」](https://www.mhlw.go.jp/toukei/saikin/hw/jinkou/kakutei25/dl/04_houdouR07.pdf)

国立社会保障・人口問題研究所の第16回出生動向基本調査では、18〜34歳の未婚者のうち「いずれ結婚するつもり」と答えた人は男性81.4％、女性84.3％でした。前回の調査（男性85.7％、女性89.3％）よりは下がっていますが、結婚を望む人は依然として多数です。

出典：[国立社会保障・人口問題研究所「第16回出生動向基本調査」](https://www.ipss.go.jp/ps-doukou/j/doukou16/doukou16_gaiyo.asp)

業界最大手のIBJは、2025年12月期の決算説明資料で、ネットワークに加盟する結婚相談所数を4,766、登録会員数を104,859名、年間の成婚組数を20,970組と公表しています。

出典：[IBJ 2025年12月期 決算説明資料（PDF）](https://www.ibjapan.jp/information/wp-content/uploads/2026/02/53ca69bd4be95e805b6dffe6bfb0af82.pdf)

## 開業に資格は必要？必要な届出は？

中小機構のJ-Net21は、結婚相談所について「開業にあたり許認可や届出は必要ない」と説明しています。そのうえで、関連する法律として特定商取引法と個人情報保護法を挙げています。

出典：[J-Net21「結婚相談所」](https://j-net21.smrj.go.jp/startup/guide/service/h033.html)

個人で始める場合は、税務署に開業届を出します。提出期限は「事業を始めた年分の確定申告期限まで」です。

出典：[国税庁「個人事業の開業届出・廃業届出等手続」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/04.htm)

個人情報保護法は、扱う個人情報の数にかかわらず適用されます。かつては5,000人分以下の事業者は対象外でしたが、平成29年5月30日の改正法施行でこの例外はなくなりました。会員の氏名・年収・写真などを扱う結婚相談所では、管理の方法を最初に決めておく必要があります。

出典：[さいたま市「個人情報保護法の改正について」](https://www.city.saitama.lg.jp/006/008/001/004/p054267.html)

## 特定商取引法で守るべきルール

結婚相手紹介サービスは、エステや学習塾などと同じく、特定商取引法の「特定継続的役務提供」の対象です。対象になるのは、**期間が2か月を超え、金額が5万円を超える契約**です。電話やインターネットを使ったサービスも含まれます。

| ルール | 内容 |
|---|---|
| 契約前の書面 | 契約の概要を書いた書面（概要書面）を渡す |
| 契約後の書面 | 契約内容を明らかにした書面（契約書面）を、遅滞なく渡す |
| クーリング・オフ | 書面を受け取った日から8日以内なら、会員は書面または電磁的記録で契約を解除できる |
| 中途解約の上限（サービス開始前） | 請求できる損害賠償などは3万円まで |
| 中途解約の上限（サービス開始後） | 2万円または契約残額の20％のいずれか低い額に、提供済みサービスの対価を加えた額まで |
| 禁止行為 | 誇大広告、事実と違うことを告げる、威迫して困惑させる など |

「入会金は返金しない」といった特約も、このルールに沿わないものは無効になります。料金表や契約書を作るときは、最初からこの上限に合わせておく必要があります。

出典：[消費者庁 特定商取引法ガイド「特定継続的役務提供」](https://www.no-trouble.caa.go.jp/what/continuousservices/)／[同 Q&A](https://www.no-trouble.caa.go.jp/qa/continuousservices.html)

連盟に加盟すると、契約書のひな形などが用意されていることがあります。独立して始める場合は、自分で整える必要があります。

## 収益の仕組み

J-Net21によると、結婚相談所は会員制が一般的で、入会金・月会費・お見合い料・イベント参加費・成婚料などを受け取るビジネスモデルです。

TMS（全国結婚相談事業者連盟）は、加盟相談所の料金の目安として次の幅を公表しています。

| 項目 | TMSが示す目安 |
|---|---|
| 入会初期費用 | 30,000円〜100,000円 |
| 月会費 | 5,000円〜15,000円 |
| お見合い費 | 5,000円〜15,000円 |
| 成婚費 | 200,000円〜300,000円 |

出典：[J-Net21「結婚相談所」](https://j-net21.smrj.go.jp/startup/guide/service/h033.html)／[TMS「収益モデル」](https://www.nakoudonet.com/kaigyo/model)

売上の大きな部分を成婚料が占める一方、成婚までには時間がかかります。開業直後は会員数が少なく、月会費だけでは固定費をまかなえない時期があることを前提に計画を立てるのが現実的です。

## 連盟に加盟するか、独立するか

連盟に加盟すると、ほかの相談所の会員を自分の会員に紹介できます。自分の会員が少ない開業直後でも、お見合いの相手を用意できるのが最大の利点です。費用は連盟によって大きく違います。

| | IBJ | TMS |
|---|---|---|
| 加盟金 | 個人200万円／法人400万円（税抜） | 85万円（税別） |
| 研修費 | 加盟金に含む | — |
| 毎月の費用 | ネットワーク月会費1万5,000円＋カウンセラー1名につき3,800円、会員1名につき月750円（税抜） | 公式ページで確認できず |
| ロイヤリティ | 0円 | — |
| ネットワークの規模 | 相談所4,766、会員104,859名（2025年12月期末） | 1,400以上の相談所が加盟（自社発表、基準日の記載なし） |

出典：[IBJ「開業に必要な資金」](https://www.ibjapan.com/kaisetu/reason/capital/)／[TMS「開業資金」](https://www.nakoudonet.com/kaigyo/shikin/)／[TMS 公式note](https://note.com/tms_renmei/n/na07ad3585bb5)

IBJは加盟金が高い分、ネットワークの会員数が多く、分割払い（3〜84回）にも対応しています。TMSは加盟金を抑えて始められます。どちらを選ぶかは、初期費用と「紹介できる会員の多さ」のどちらを重く見るかで決まります。

## 開業前に確認したいこと

1. **加盟金以外の毎月の費用**：ネットワーク月会費、会員1人ごとの費用がいくらかかるか
2. **契約書・料金表のひな形**：特定商取引法に沿った書面を用意してもらえるか
3. **研修と開業後のサポート**：カウンセリングや集客の研修があるか
4. **紹介できる会員の規模**：自分の会員がお見合いできる相手がどれだけいるか

金額や条件は変わることがあります。気になる連盟や本部は、資料請求や説明会で最新の内容を確認してください。
