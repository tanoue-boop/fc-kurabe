「フランチャイズ 補助金」で検索すると、使える制度の一覧（小規模事業者持続化補助金、IT導入補助金、自治体の創業補助金、雇用の助成金など）と、「後払いなので開業資金には直接充てにくい」という注意を中心にした記事が多く見つかります。加盟金が対象外と書いた記事もありますが、調べた範囲では、**公募要領のどの規定で対象外になるのか**、**本部から買う機材や本部指定の機器はどうか**、**交付決定前に発注した費用が対象外になるため、開業準備の時期と合うのか**まで原文で示した記事は見つかりませんでした。この記事では、国の「小規模事業者持続化補助金＜創業型＞」と、自治体の例として東京都の「創業助成事業」の公募要領・募集要項を読み、フランチャイズ加盟店にかかわる規定を整理します。融資は[フランチャイズの開業資金と融資](/guide/funding/)、自治体の特定創業支援等事業の証明書は[地方でフランチャイズ開業するときの確認点](/guide/chiho/)で扱っています。

## 結論：フランチャイズ開業で補助金・助成金を考えるときの要点

- **本部に払う費用は、持続化補助金の対象になりません。** 公募要領は、補助対象外の経費として「自社内部やフランチャイズチェーン本部との取引によるもの（フランチャイズチェーン指定の機器等を本部以外から購入する場合等も含みます）」を挙げています。保証金、研修の受講費も対象外の経費に入っています。
- **交付決定より前に発注・契約・支払いをした費用は対象外です。** 持続化補助金＜創業型＞の第4回は、申請受付締切が2026年12月15日、採択発表が2027年3月頃の予定で、交付決定はそこからさらに概ね1〜2か月かかる場合があるとされています。開業前にそろえる設備の支払いには合いにくく、開業後の販路開拓の費用に向く制度です。
- **補助金・助成金は後払いです。** どちらの制度も、事業を実施して経費を支払い、実績報告と検査を受けてから支払われます。開業資金は、補助金・助成金がなくても足りる計画にしておく必要があります。東京都の募集要項も「助成金の交付がない場合であっても、事業の実施が可能な資金計画であること」を申請要件にしています。

## 補助金・助成金は「後払い」で、審査がある

持続化補助金＜創業型＞の公募要領は、注意事項の冒頭で「本補助金は、審査があり、不採択になる場合があります。」「補助事業遂行の際には自己負担が必要となり、補助金は後払いです。」と書いています。支払いを受けた補助金は「原則として、融資のように返済の必要がありません」とされる一方、収益納付や処分制限財産の処分によって減額等がされる場合があるとも書かれています。

東京都の創業助成事業も、募集要項のスケジュール欄に「助成金は後払いです」と明記し、助成対象期間の終了後（中間払いは6か月経過以降）に実績報告・検査を経て支払うとしています。

出典：[小規模事業者持続化補助金＜創業型＞事務局「第4回公募 公募要領」（第9版：2026年11月5日）](https://r6.jizokukahojokin.info/sogyo/doc/r6_koubover9_sogyo4.pdf)／[東京都中小企業振興公社「令和８年度 第２回創業助成事業【募集要項】」](https://startup-station.jp/wp-content/uploads/r8_2_bosyuyoko_sogyojosei_20260616.pdf)

## 小規模事業者持続化補助金＜創業型＞の概要

持続化補助金＜創業型＞は、産業競争力強化法にもとづく「特定創業支援等事業」による支援を受けた小規模事業者が行う、販路開拓等の取り組みの経費の一部を補助する制度です。

| 項目 | 公募要領の記載（第4回・第9版） |
|---|---|
| 補助率 | 2／3 以内 |
| 補助上限 | 200 万円（インボイス特例の要件を満たす場合は50万円上乗せ） |
| 対象経費 | 機械装置等費、広報費、ウェブサイト関連費、展示会等出展費（オンラインによる展示会・商談会等を含む）、旅費、新商品開発費、借料、委託・外注費 |
| 申請要件 | 「特定創業支援等事業」による支援を受けた日および開業日（設立年月日）が、公募締切時から起算して過去1か年の間であること |
| 対象にならない人 | 申請時点で開業していない創業予定者（開業届を出していても、開業届上の開業日が申請日より後の場合は対象外） |
| 小規模事業者の範囲 | 商業・サービス業（宿泊業・娯楽業除く）は常時使用する従業員の数5人以下 など |
| 第4回の日程 | 申請受付締切 2026年12月15日（火）17:00／事業支援計画書（様式4）発行の受付締切 2026年12月4日（金）／採択発表予定 2027年3月頃／補助事業実施期限 2028年3月31日（金） |

申請には、地域の商工会・商工会議所から「事業支援計画書」（様式4）の発行を受けることと、「ＧビズＩＤプライム」のアカウントが必要です。開業前でも、店舗がオープン準備中であれば対象になり得るとされていますが、「補助事業終了までに商品またはサービスの提供を開始し、事業活動を開始することが必要」とされています。

補助上限の200万円を受けるには、補助率2／3から逆算すると、補助対象になる経費が300万円以上必要です。

特定創業支援等事業の証明書の取り方は[地方でフランチャイズ開業するときの確認点](/guide/chiho/)、インボイス特例にかかわる適格請求書発行事業者の登録は[加盟金・ロイヤリティの消費税とインボイス](/guide/invoice/)にまとめています。

出典：[小規模事業者持続化補助金＜創業型＞事務局「第4回公募 公募要領」（第9版：2026年11月5日）](https://r6.jizokukahojokin.info/sogyo/doc/r6_koubover9_sogyo4.pdf)

## 持続化補助金で、フランチャイズ加盟店が対象外になる費用

公募要領の「補助対象外となる経費」には、フランチャイズに直接かかわる規定があります。

| 公募要領の記載 | フランチャイズでの読み方 |
|---|---|
| 「自社内部やフランチャイズチェーン本部との取引によるもの（フランチャイズチェーン指定の機器等を本部以外から購入する場合等も含みます）」 | 本部に払う加盟金や、本部から買う機材は対象外。本部が指定する機器は、本部以外の業者から買っても対象外 |
| 広報費の対象とならない経費例「フランチャイズ本部の作製する広告物の購入」 | 本部が作ったチラシ・販促物を買う費用は対象外 |
| 「駐車場代、保証金、敷金、仲介手数料、光熱水費」 | 本部に預ける保証金、店舗の敷金・仲介手数料は対象外 |
| 「講習会・勉強会・セミナー研修等参加費や受講費、図書等の資料購入費」 | 研修の受講費は対象外 |
| 「売上高や販売数量、契約数等に応じて課金される経費や成功報酬型の費用」 | 売上に応じて課金される費用は対象外 |
| 「販売している商品の仕入」 | 本部などからの商品の仕入れは対象外 |
| 自動車等車両（「自動車」「キッチンカー」「キッチントレーラー」など） | 移動販売や出張サービスの車両の購入は対象外 |
| 「事務所等に係る家賃は補助対象となりません。」（ただし、新たな販路開拓の取組の一環として新たに事務所等を賃借する場合は対象となる場合がある） | 店舗の家賃は原則として対象外 |

このほか、パソコン・タブレット端末・複合機などの「汎用性が高く目的外使用になりえるもの」、不動産の購入・取得費も対象外です。

本部に払うロイヤリティについては、公募要領に「ロイヤリティ」という語はありませんが、上の「フランチャイズチェーン本部との取引によるもの」にあたります。**加盟金・研修費・保証金・ロイヤリティ・本部からの仕入れなど、本部に払うお金はこの補助金の対象にならない**と考えて資金計画を立てます。

一方で、対象になり得る経費の例として、公募要領は店舗改装・バリアフリー化工事（委託・外注費）、看板作成・設置やチラシの外注（広報費）、商品販売のためのウェブサイト作成（ウェブサイト関連費）などを挙げています。ただし、広報費とウェブサイト関連費は、それぞれ「補助金交付申請額の上限は 30 万円」で、ほかの経費と一緒に申請する必要があります。本部が内装業者や看板の仕様を指定している場合に「本部指定」の規定にかかるかどうかは、契約の内容によって変わるため、申請前に商工会・商工会議所と補助金事務局に確かめます。

出典：[小規模事業者持続化補助金＜創業型＞事務局「第4回公募 公募要領」（第9版：2026年11月5日）](https://r6.jizokukahojokin.info/sogyo/doc/r6_koubover9_sogyo4.pdf)

## 交付決定前の支出は対象外：開業準備の時期と合うか

公募要領は、補助対象となる経費の条件を「交付決定日以降に発生し補助事業実施期間中に支払が完了した経費」とし、「交付決定前に発注・契約、購入、支払い（前払い含む）等を実施したもの」を対象外としています。採択通知書が届いただけでは補助事業を始めることはできず、「交付決定日前に行われた発注・契約・支出行為は、補助対象外です」とも書かれています。

第4回の日程に当てはめると、次のようになります。

| 時期 | 内容（公募要領の予定） |
|---|---|
| 2026年12月4日（金） | 事業支援計画書（様式4）発行の受付締切 |
| 2026年12月15日（火）17:00 | 申請受付締切 |
| 2027年3月頃 | 採択発表予定 |
| 採択発表から概ね1〜2か月 | 交付決定（見積書等の提出後。目安で、状況により変動） |
| 2028年3月31日（金） | 補助事業実施期限 |

フランチャイズでは、加盟契約から研修・物件の決定・内装工事・開店までの準備が続きます（[フランチャイズ開業までの流れと期間](/guide/nagare/)）。**開店前にそろえる内装や設備の発注が交付決定より前になれば、その費用は対象になりません。** 補助金を使う場合は、開店前の設備ではなく、開業後に行うチラシ・看板・ウェブサイトなどの販路開拓の費用に充てる計画のほうが、制度の時期と合わせやすいと言えます。

また、申請時点で開業している必要があり、特定創業支援等事業の支援を受けた日と開業日がいずれも公募締切から過去1か年以内であることが要件です。開業日（個人事業主は開業届の「開業・廃業等日」）をいつにするかで、申請できる回が変わります。

出典：[小規模事業者持続化補助金＜創業型＞事務局「第4回公募 公募要領」（第9版：2026年11月5日）](https://r6.jizokukahojokin.info/sogyo/doc/r6_koubover9_sogyo4.pdf)

## 自治体の創業助成の例：東京都「創業助成事業」

自治体にも創業者向けの補助金・助成金があります。例として、東京都中小企業振興公社が実施する「創業助成事業」（令和8年度第2回）の募集要項の主な内容をまとめます。

| 項目 | 募集要項の記載（令和8年度第2回） |
|---|---|
| 助成率 | 助成対象と認められる経費の２／３以内 |
| 助成限度額 | 上限額４００万円 下限額１００万円（事業費及び従業員人件費は300万円、委託費は100万円が限度） |
| 助成対象経費 | 事業費（賃借料、広告費、器具備品購入費、産業財産権出願・導入費、専門家指導費）、従業員人件費、委託費（市場調査・分析費） |
| 助成対象期間 | 交付決定日（令和９年３月１日予定）から６か月以上２年が経過する日までの間で事業に必要な期間 |
| 申請受付 | 令和８年９月２９日（火）～令和８年１０月８日（木）。第1回は令和8年4月7日～4月16日で、令和8年度はいずれも受付終了 |
| 申請できる人 | 都内での創業を具体的に計画している個人、法人登記・開業の届出から5年未満の法人代表者・個人事業主など（経営経験が通算5年以上の方は不可） |
| 申請要件2 | 指定された23の創業支援事業（TOKYO創業ステーションの事業計画書策定支援、都内区市町村の認定特定創業支援等事業、東京都中小企業制度融資（創業）の利用など）のいずれかを満たすこと |

フランチャイズの費用にかかわる規定には、次のものがあります。

- **賃借料**：都内の事務所・店舗等の賃借料は対象ですが、「事務所・店舗等の賃貸借契約に関する敷金・礼金・保証金・手数料・更新料等」は対象外です。賃借料と従業員人件費に限り、交付決定日以前に契約した内容も対象になります。
- **器具備品購入費**：「１点あたりの購入単価が、税込１万円以上５０万円未満のもの」が対象で、中古品や、建物附属設備を含む機械装置、自動車等の車両は対象外です。
- **創業前の支出**：「創業前に契約・履行・支出した経費は助成対象になりません。」税務署に開業の届出をした後に契約・履行・支出した経費が対象です。

募集要項には「フランチャイズ」「加盟金」「ロイヤリティ」という語は出てきませんでした。助成対象経費は上の7つの経費明細に限られているため、加盟金・研修費・ロイヤリティはいずれの区分にもあたりません。また、申請要件には「代表者以外の主体が、実質的な経営に関する指揮、命令、監督等を継続して行っていない、または行う予定ではないこと」「他の個人事業主、または他の法人の実施事業の承継や譲渡ではないこと」があります。**フランチャイズ加盟店としての創業がこれらの要件をどう満たすかは募集要項に書かれていないため、申請前に東京都中小企業振興公社に確認します。**

東京都以外の自治体の制度は、名称・対象経費・要件がそれぞれ違います。出店する市区町村や都道府県の産業振興の窓口で、募集要項の対象経費と対象外経費を確かめます。

出典：[東京都中小企業振興公社「令和８年度 第２回創業助成事業【募集要項】」](https://startup-station.jp/wp-content/uploads/r8_2_bosyuyoko_sogyojosei_20260616.pdf)／[東京都「創業助成事業」報道発表（2026年2月16日）](https://www.metro.tokyo.lg.jp/information/press/2026/02/2026021609)

## 当サイトのデータ：開業資金の帯と、制度の上限

補助金・助成金の上限額を補助率（2／3）で割り戻すと、上限まで受けるのに必要な対象経費は、東京都の創業助成の下限額（100万円）で150万円、持続化補助金＜創業型＞の上限（200万円）で300万円、東京都の創業助成の上限額（400万円）で600万円です。当サイトで開業資金を金額で確認できた117本部（2026年11月25日時点、data/brands.json を集計）を、この区切りで数えました。

| 開業資金（公表値） | 本部数 |
|---|---|
| 150万円以下 | 34 |
| 150万円超〜300万円以下 | 20 |
| 300万円超〜600万円以下 | 26 |
| 600万円超 | 37 |

開業資金の中央値は350万円です。ただし、この開業資金には加盟金・研修費・保証金など、上で見たとおり補助の対象にならない費用が含まれています。**開業資金が300万円を超えていても、そのうち補助対象になる経費が300万円あるとは限りません。** 税込・税抜の表記も本部によって混ざっています。

開業資金の金額帯ごとの本部一覧は、[100万円以下](/shikin/under-100/)・[101〜300万円](/shikin/100-300/)・[301〜500万円](/shikin/300-500/)・[501〜1,000万円](/shikin/500-1000/)・[1,000万円超](/shikin/over-1000/)にあります。

## 受け取った補助金・助成金と税金

持続化補助金の公募要領は、「補助金は経理上、補助金の額の確定を受けた事業年度における収益として計上するものであり、法人税・所得税の課税対象となります。」としています。あわせて、この補助金は所得税法第42条・法人税法第42条に規定する国庫補助金等に該当し、補助金を交付の目的に適合した固定資産の取得または改良に充てた場合には、これらの規定を適用できるとしています。

東京都の創業助成事業は、助成事業の完了した年度の翌年度から起算して5年間、都内で事業活動を継続することや、企業化状況報告書の提出、収益が一定以上出た場合の収益納付などを求めています。また、助成事業で取得した50万円以上の広告物等の財産を一定期間内に処分（目的外使用、売却、譲渡、廃棄など）するときは、あらかじめ公社の承認が必要です。持続化補助金でも、単価50万円（税抜き）以上の機械装置等は「処分制限財産」にあたり、処分には補助金事務局の承認が必要です。

加盟金そのものの税務処理は[フランチャイズの加盟金の税務・会計処理](/guide/kameikin-zeimu/)にまとめています。

## 補助金・助成金を考えるときに確かめること

1. **開業資金が補助金なしで足りるか**：補助金・助成金は審査があり、後払いです。採択されなくても開業できる資金計画になっているか
2. **本部に払う費用と、それ以外の費用を分ける**：加盟金・研修費・保証金・ロイヤリティ・本部からの仕入れは、持続化補助金では本部との取引として対象外。本部指定の機器は本部以外から買っても対象外
3. **交付決定と発注の順番**：交付決定前に発注・契約・支払いをした費用は対象外。開店前の設備ではなく、開業後の販路開拓に使う計画になっているか
4. **申請できる時期**：持続化補助金＜創業型＞は、申請時点で開業していること、特定創業支援等事業の支援を受けた日と開業日が公募締切から過去1か年以内であること。東京都の創業助成は、創業前の支出が対象外
5. **加盟店であることと要件**：自治体の助成金で、本部の指導を受けることや既存の事業の承継にあたる要件がある場合は、フランチャイズ加盟店が対象になるかを実施機関に確認したか
6. **本部の説明と公募要領の原文**：本部や業者から「補助金が使える」と案内された場合も、最新の公募要領・募集要項の対象経費と対象外経費を自分で確かめたか

本部を比べる順番は[フランチャイズ本部の選び方](/guide/erabikata/)、説明会での聞き方は[フランチャイズ説明会で聞くこと](/guide/setsumeikai/)にまとめています。開業資金を抑えて始めたい場合は[低資金で開業できるフランチャイズ](/tag/teishikin/)も参考にしてください。

補助金・助成金の公募要領は回ごとに改定されます。申請する時点の最新の公募要領・募集要項を、補助金事務局・商工会・商工会議所・自治体の窓口で確認してください。
