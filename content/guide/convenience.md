コンビニは全国で5万6千店を超える身近な業態で、当サイトにもファミリーマートの加盟店募集を掲載しています。一方で、ロイヤリティ（本部フィー）の計算方法や営業時間、酒・たばこの許可など、ほかの業種のフランチャイズとは仕組みが違う点が多くあります。この記事では、コンビニに加盟するときの契約の仕組みと手続き、当サイトに掲載している小売系の本部のデータを整理します。

## 結論：コンビニ・小売店開業の要点

- **コンビニの契約は「土地・建物を本部が用意するか、自分で用意するか」で分かれます。** ファミリーマートは4つの契約タイプがあり、本部フィーは月の営業総利益に対して36％〜69％と、タイプと利益額で変わります。契約期間はどのタイプも開店から10年間です。
- **酒とたばこを売るには、それぞれ許可が要ります。** 酒類は税務署の販売業免許（登録免許税3万円）、たばこは財務大臣の小売販売業許可（登録免許税15,000円）で、たばこには最寄りの販売店との距離や月間4万本の取扱予定高といった基準があります。
- **当サイトの「小売店・コンビニ」の掲載本部は5本部です。** 開業資金の掲載値がある4本部は100万〜400万円で、コンビニとは費用も働き方も大きく違います。

経済産業省の商業動態統計（2025年分速報）によると、全国のコンビニエンスストアの販売額は13兆3,212億円で前年より3.4％増え、店舗数は56,659店で1.2％増えました。

## コンビニの契約タイプと本部フィー

ファミリーマートでは、本部に払う費用（本部フィー）を「売上」ではなく「営業総利益」に対する割合で決めています。公式ページでは、4つの契約タイプが次のように示されています。

| 契約タイプ | 土地・建物 | 内装設備工事 | 本部フィー（月の営業総利益に対する割合） |
|---|---|---|---|
| 1FC-A | オーナーが用意 | オーナーが負担 | 250万円以下の部分49％／250万1円〜350万円の部分39％／350万1円以上の部分36％ |
| 1FC-B | オーナーが用意 | 一部を本部が負担 | 250万円以下の部分52％／250万1円〜350万円の部分42％／350万1円以上の部分39％ |
| 1FC-C | 本部が用意 | オーナーが負担 | 300万円以下の部分59％／300万1円〜450万円の部分52％／450万1円以上の部分49％ |
| 2FC-N | 本部が用意 | 本部が負担 | 300万円以下の部分59％／300万1円〜550万円の部分63％／550万1円以上の部分69％ |

- 営業総利益は「商品総売上高から売上原価を引き、営業収入を足したもの」と説明されています。
- 2FC-Nは開店6年目以降に本部フィーが減額される制度があるとしています（詳細は担当者に確認）。
- 契約期間はどのタイプも開店から10年間です。

土地・建物を自分で用意するタイプほど本部フィーの割合が低く、本部が用意するタイプほど高い、という関係です。2FC-Nは利益が増えるほど割合が上がる形になっている点も、ほかのタイプと違います。

出典：[ファミリーマート「契約内容・開店までの流れ」](https://www.family.co.jp/company/fc/system/process.html)

## 加盟の条件と必要な資金

ファミリーマートは、全契約タイプで契約時に手元資金150万円（元入金。両替用の現金や商品代金の一部になる）を用意するよう案内しています。このほか、開店時にスタッフの募集や許認可の申請などで50万円ほど、店長研修の交通費・宿泊費、2〜3か月程度の生活費が別に必要としています。

| 項目 | ファミリーマートの公式情報 |
|---|---|
| 契約時必要資金 | 150万円（元入金） |
| 開店時の費用 | スタッフ募集・許認可申請などで50万円ほど |
| 1FC-Cの条件 | 開業資金のうち1,000万円程度を手元資金として用意できること、2名で専業できること |
| 2FC-Nの条件 | 18歳以上70歳以下。同居する夫婦・事実婚・同性パートナー、または同居する三親等以内の親族2名で専業すること |
| ひとりで加盟する場合 | 18歳〜54歳を対象に「ひとり加盟制度」あり |
| 店長研修 | 店舗オペレーション5日間、経営マネジメント5日間、運営実践4日間、加盟者向け1日間（変更の場合あり） |

ファミリーマートの1FC-Cと2FC-Nは、2人で専業することが条件です。副業や1人で始めることを考えている場合は、条件に合う契約タイプがあるかを最初に確認する必要があります。

出典：[ファミリーマート「加盟店募集」](https://www.family.co.jp/company/fc.html)／[同「契約内容・開店までの流れ」](https://www.family.co.jp/company/fc/system/process.html)

## 開業に必要な許可・届出

### 酒類の販売業免許

酒類を売るには、販売場の所在地を所轄する税務署で販売業免許を受けます。申請の手数料はかかりませんが、免許1件につき登録免許税3万円がかかります。標準処理期間は原則2か月以内です。また、販売場ごとに「酒類販売管理者」を選び、3年を超えない期間ごとに研修を受けさせる必要があります。

出典：[国税庁「酒類販売業免許の申請」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/sake/annai/23600071.htm)／[国税庁「一般酒類小売業免許申請の手引」](https://WWW.NTA.GO.JP/taxes/sake/menkyo/tebiki/01.pdf)

### たばこ小売販売業の許可

たばこを売るには、財務大臣の小売販売業許可が必要です。申請書は予定営業所の最寄りの日本たばこ産業（JT）の支社に出し、許可を受けたら登録免許税15,000円を納めます。標準処理期間は「申請書を受理した日の属する月の末日から2月以内」です。

許可には基準があり、次のような場合は不許可になります。

| 基準 | 内容 |
|---|---|
| 距離 | 最寄りのたばこ販売店までの距離が基準に足りない（例：市制施行地の市街地で150m、住宅地で200m〜300m） |
| 取扱予定高 | 予定営業所での取扱予定高が月間4万本に満たない |
| 場所 | 袋小路に面しているなど、たばこの購入に著しく不便な場所 |
| 使用権 | 予定営業所を使う権利がない（許可後1か月以内に開業の見込みがない場合を含む） |

距離の基準は、地域（指定都市・市制施行地・町村制施行地）と環境（繁華街・市街地・住宅地）の組み合わせで25m〜300mと決まっています。環境区分は申請後のJTの現地調査で決まります。沖縄県では距離と取扱高の基準は適用されません。

出典：[財務省「製造たばこ小売販売業の許可」](https://www.mof.go.jp/policy/tab_salt/tobacco/tobacco_kouri_kyoka.html)／[財務省「小売販売申請者向けリーフレット」（令和8年10月13日改正）](https://www.mof.go.jp/policy/tab_salt/tobacco/leaflet20261013.pdf)

### 食品衛生法の営業届・営業許可

弁当などの食品を販売する場合は、保健所への「営業届」や、扱い方によっては「営業許可」が必要です。横浜市は、コンビニやスーパーでは「営業届をしたこととみなされた業種」と実際の主な業種が違うケースがあり、その場合は改めて営業届が必要だと案内しています。店内で調理をするかどうかで必要な手続きが変わるため、出店先の保健所に確認してください。

出典：[横浜市「食品衛生法に基づく営業届出制度について」](https://www.city.yokohama.lg.jp/kenko-iryo-fukushi/kenko-iryo/shoku/yokohamaWEB/gyomu/tetuduki/todokedeannai.html)

個人で始める場合の開業届や、フランチャイズ本部が加盟前に渡す書面（中小小売商業振興法）については、[独立開業の進め方](/guide/dokuritsu/)にまとめています。中古品を買い取って売る業態は古物商許可が必要です（[買取店の開業ガイド](/guide/kaitori/)）。

## 加盟前に知っておきたい公正取引委員会のルール

公正取引委員会は、コンビニの実態調査を踏まえて、令和3年4月に「フランチャイズ・システムに関する独占禁止法上の考え方」を改正しました。この中で、次の点が示されています。

- 本部が予想売上や予想収益を示す場合は、似た環境にある既存店の実績など、根拠のある事実や合理的な計算方法に基づく必要がある。
- 加盟後に、店の周辺に本部が同じ業種の店を出す（ドミナント出店）ことについて、加盟希望者に開示することが望ましい。
- 正当な理由なく、品質が急に落ちる商品の見切り販売を制限して廃棄させることは、優越的地位の濫用に当たりうる。
- 24時間営業などで損益が悪化していることを理由に営業時間の短縮を求める加盟者に対し、正当な理由なく協議を一方的に拒むことは、優越的地位の濫用に当たりうる。

説明会や契約前の説明では、これらの点について本部がどう扱っているかを確認しておくと安心です。

出典：[公正取引委員会「フランチャイズ・システムに関する独占禁止法上の考え方」](https://www.jftc.go.jp/dk/guideline/unyoukijun/franchise.html)／[同 改正の公表（令和3年4月28日）](https://www.jftc.go.jp/houdou/pressrelease/2021/apr/210428fcgl.html)

## 個人とフランチャイズ、どちらで始める？

| | 個人で始める小売店 | コンビニのフランチャイズ |
|---|---|---|
| 店舗 | 自分で用意する | 本部が用意する契約タイプもある |
| 本部への支払い | なし | 営業総利益に対する割合（タイプ・利益額で変動） |
| 営業時間・品ぞろえ | 自分で決める | 契約と本部の方針に沿う |
| 契約期間 | なし | ファミリーマートは開店から10年間 |
| 酒・たばこの許可 | 自分で申請する | 自分で申請する（本部の支援の有無は要確認） |

コンビニは店舗を本部が用意する契約タイプがあり、手元資金を抑えて店を持てる一方、本部に払う割合が高く、契約期間も長くなります。

## 本部を選ぶときに確認したいこと

1. **本部フィーの計算のもと**：売上ではなく営業総利益に対する割合か、廃棄した商品の原価がどう扱われるか
2. **契約タイプと専業の条件**：2人で専業する必要があるか、1人で加盟できる制度があるか
3. **営業時間**：24時間営業が前提か、時短営業の相談ができるか
4. **近くへの出店**：周辺に同じチェーンの店が出る可能性について、どう説明されているか
5. **予想売上の根拠**：示された売上予測が、どの既存店の実績にもとづいているか
6. **酒・たばこの許可**：取得の手続きを誰が行うか、たばこの距離基準を満たす場所か
7. **中途解約の条件**：10年の契約期間の途中でやめる場合の違約金

金額や条件は変わることがあります。気になる本部は、資料請求や説明会で最新の内容を確認してください。
