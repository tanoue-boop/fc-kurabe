買取店は、小さな店舗や出張買取から始められる業種です。この記事では、開業前に押さえておきたい「市場」「許可と届出」「買い取るときのルール」「お金」を、公的機関の情報と各本部の公表値で整理します。

## 結論：買取店開業の要点

- **古物商許可が必要です。** 主たる営業所の所在地を管轄する警察署に申請し、手数料は19,000円です。許可を受けたあとも、買い取るときの相手方の確認、帳簿への記録（3年間保存）などの義務があります。出張買取は特定商取引法の「訪問購入」のルールもかかります。
- **当サイトで開業資金を確認できた買取の本部8件では、220万円から1,200万円まで幅があります。** 物件取得費が含まれるかどうかなど、金額の範囲は本部によって違います。
- **ロイヤリティは「毎月の固定額」が中心です。** 掲載10本部のうち、金額を公表している固定額制が5本部、固定額＋売上の一部が1本部で、確認できた中に売上の割合だけで決まる本部はありませんでした。

環境省の「令和6年度リユース市場規模調査報告書」では、2024年の国内のリユース市場規模（一般消費者がリユース品を購入した総額。自動車・バイクを含む）を**3兆4,986億円**と推計しています。環境省は2026年3月の「リユース等の促進に関するロードマップ」でもこの数字を示し、2030年に約4兆円に達するという民間推計も紹介しています。

## 開業に必要な許可・届出

中古品を買い取って売るには、都道府県公安委員会の**古物商許可**が必要です。

| 手続き | 提出先 | 費用・期間など |
|---|---|---|
| 古物商許可申請 | 主たる営業所の所在地を管轄する警察署 | 手数料19,000円。神奈川県警は許可証交付まで「概ね40日」と案内 |
| 管理者の選任 | — | 営業所ごとに管理者1人を選ぶ（古物営業法第13条第1項） |
| 個人事業の開業届出書 | 納税地を所轄する税務署 | 事業を始めた年分の確定申告期限まで |
| 青色申告承認申請書（青色申告をする場合） | 同上 | 年の途中で開業した場合は、開業日から2か月以内 |

出典：[J-Net21「貴金属買取」](https://j-net21.smrj.go.jp/startup/guide/proservice/02.html)／[警視庁「古物商許可申請」](https://www.keishicho.metro.tokyo.lg.jp/tetsuzuki/kobutsu/tetsuzuki/kyoka.html)／[神奈川県警察（古物商許可申請の案内）](https://www.police.pref.kanagawa.jp/tetsuzuki/eigyokankei/kobutsu/mesd0019.html)／[国税庁「個人事業の開業届出・廃業届出等手続」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/04.htm)／[国税庁「所得税の青色申告承認申請手続」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/09.htm)

許可証が交付されるまでの期間を見込んで、開店日を決めておく必要があります。

## 古物商が買い取るときに守るルール

古物営業法では、買い取るたびに次のことが求められます。

| ルール | 内容 |
|---|---|
| 相手方の確認 | 古物を買い受けるとき、売る人の住所・氏名・職業・年齢を確認する。古物商同士の取引でも免除されない |
| 確認が免除される取引 | 対価の総額が1万円未満の取引は、原則として確認と帳簿への記載が免除。ただしバイク、ゲームソフトなどは1万円未満でも対象 |
| 帳簿等への記録 | 取引のたびに帳簿等に記載するか電磁的方法で記録し、最終の記載・記録の日から3年間、営業所に備え付ける |
| 不正品の申告 | 不正品の疑いがあると認めるときは、直ちに警察官に申告する |
| 標識の掲示 | 公衆の見やすい場所に、決められた様式の標識を掲示する |
| 取引の場所 | 営業所か、取引の相手方の住所・居所以外の場所では、古物商以外の人から古物を受け取れない。仮設店舗（催事など）で買い取る場合は、営業日の3日前までに届け出る |

2025年10月1日からは、エアコンの室外機、電気温水機器のヒートポンプ、電線、金属製のグレーチングが、1万円未満でも確認・記録が必要な品目に加わりました。

出典：[警視庁（古物営業の解説）](https://www.keishicho.metro.tokyo.lg.jp/tetsuzuki/kobutsu/kaisetsu/kobutsu_shinsei.html)／[警視庁「古物営業法施行規則の一部改正について（令和7年10月1日施行）」](https://www.keishicho.metro.tokyo.lg.jp/tetsuzuki/kobutsu/kaisetsu/kobutsu_sekoukisoku.html)／[和歌山県警察「古物営業の手引き」（令和7年10月）](https://www.police.pref.wakayama.lg.jp:443/03_soudan/seian_todokede/documents/tebiki.pdf)

## 出張買取は特定商取引法の「訪問購入」

お客様の自宅などに出向いて買い取る出張買取は、特定商取引法の「訪問購入」に当たります。事業者には次のルールがあります。

| ルール | 内容 |
|---|---|
| 飛び込み勧誘の禁止 | 勧誘を求めていない人への勧誘（不招請勧誘）は禁止。勧誘の前に、事業者名や物品の種類を明示する |
| 再勧誘の禁止 | 一度断った人への再勧誘は禁止 |
| 書面の交付 | 物品の種類や特徴、購入価格、引渡しの拒絶やクーリング・オフに関する事項などを書いた書面を渡す |
| クーリング・オフ | 書面の交付から8日以内なら、売った人は無条件で契約を解除できる |
| 引渡しの拒絶 | クーリング・オフ期間中、売った人は物品の引渡しを拒める |
| 第三者への引渡し | 期間中に物品を第三者に渡した場合は、その情報を売った人に伝え、第三者にもクーリング・オフの対象物品であることなどを書面で通知する |

自動車（二輪を除く）、家具、家電、本、CDやDVD、ゲームソフト類などは訪問購入の規定の適用除外ですが、再勧誘の禁止など一部の規制は除外されません。

出典：[静岡県掲載資料「ご存知ですか？訪問購入のルール」](https://www.pref.shizuoka.jp/_res/projects/default_project/_page_/001/002/400/zigyoushamuke.pdf)／[大阪府「訪問購入（訪問買取）について知りたい」](https://www.pref.osaka.lg.jp/faq/faq_000102.html)

出張買取をうたう本部に加盟する場合は、本部が用意する契約書面がこれらの記載事項に沿っているかを確認しておくと安心です。

## 貴金属・消費税で知っておきたいこと

**貴金属の高額な現金取引**：犯罪収益移転防止法では、古物商が貴金属などについて**200万円を超える現金取引**をするときに、取引時確認と、確認記録・取引記録の作成・保存（各7年間）が求められます。犯罪による収益の疑いがある場合は、疑わしい取引の届出も必要です。

出典：[熊本県警察「犯罪収益移転防止法で求められる古物商の義務」](https://www.pref.kumamoto.jp/site/police/8565.html)／[福島県警察「犯罪収益移転防止法における古物商及び質屋の義務等について」](https://www.police.pref.fukushima.jp/03.tetuduki/-seian/kobutu/hanzaisyuekiitenbousihou.pdf)／[大阪府警察「宝石・貴金属等取扱事業者の義務等（疑わしい取引の届出）」](https://www.police.pref.osaka.lg.jp/seikatsu/hanzaisyueki/1/kobutsu/4091.html)

**消費税の「古物商特例」**：買取店の仕入れ先の多くは、インボイス（適格請求書）を発行しない一般の人です。国税庁によると、古物商がインボイス発行事業者以外の者から古物（棚卸資産）を買い受けた場合は、一定の事項を記載した**帳簿の保存だけで仕入税額控除ができます**。帳簿には、通常の記載事項に加えて特例の対象である旨などを書きます。古物営業法の帳簿（古物台帳）とあわせて保存する方法も示されており、その場合の保存期間は確定申告書の提出期限の翌日から7年間です。

出典：[国税庁「インボイス制度（基礎編）」（令和8年5月）](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/pdf/0023011-048_02.pdf)／[国税庁「インボイス制度に関するQ&A」問110](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/pdf/qa/110.pdf)

古物営業法の保存期間（3年）と、消費税のための保存期間（7年）は違います。帳簿の付け方や保存の仕組みを本部が用意しているかどうかも、加盟前に確認したい点です。

## 個人とフランチャイズ、どちらで始める？

| | 個人で独立 | フランチャイズに加盟 |
|---|---|---|
| 古物商許可 | 必要 | 必要 |
| 初期費用 | 物件・内装・備品・広告・買取資金が中心 | 加盟金・研修費・システム費などが加わる |
| 毎月の支払い | なし | ロイヤリティ（固定額が中心） |
| 査定・真贋の知識 | 自分で身につける | 本部の研修や査定の支援があるか確認する |
| 買い取った品の売り先 | 自分で探す | 本部の販路を使えるか確認する |
| 集客 | 自分で集める | 本部のブランドや集客支援があるか確認する |

査定や売り先の知識と経験がある場合は個人で、査定・販路・集客の仕組みを本部に頼りたい場合はフランチャイズで、という分け方が考えられます。

## 本部を選ぶときに確認したいこと

1. **開業資金に含まれるもの**：物件取得費・内装・広告費が入っているか、別途か。買取資金をいくら見込んでいるか
2. **ロイヤリティの額と条件**：固定額はいくらか、売上に応じた上乗せがあるか、開業直後の減免があるか
3. **査定と売り先の支援**：真贋・査定の研修、買い取った品の販路（本部の買い取り・オークションなど）
4. **法令対応の仕組み**：本人確認・帳簿の記録、出張買取の契約書面（訪問購入）、インボイスの古物商特例に沿った帳簿の付け方
5. **契約期間と解約の条件**：契約期間（掲載本部の公表値では3年〜15年と幅がある）、途中でやめるときの違約金の有無

金額や条件は変わることがあります。気になる本部は、資料請求や説明会で最新の内容を確認してください。
