ネットショップや、モール・フリマアプリでの物販は、店舗を持たずに自宅から始められる仕事です。この記事では、**ネットで商品を売る仕事を開業するときの「許可」「表示のルール」「お金」**を、公的機関の情報と各本部の公表値で整理します。中古品を買い取って売る店舗を開く場合は[買取店の開業ガイド](/guide/kaitori/)をご覧ください。

## 結論：ネットショップ・物販開業の要点

- **中古品を「買い取って」売るなら古物商許可が必要です。** 自分で使っていた物の販売や、自分が海外で購入した物の輸入販売などは許可がいりません（熊本県警の案内）。新品の仕入れ販売でも、仕入れ先によっては「古物」にあたることがあります。
- **ネットで売ることは特定商取引法の「通信販売」にあたります。** 販売価格・送料、事業者の氏名・住所・電話番号、返品の可否などを広告（商品ページ）に表示する義務があり、2022年6月からは注文確定の直前の画面（最終確認画面）にも表示が必要です。
- **当サイトに掲載している物販系の本部は5件で、開業資金を確認できた4件は32万円〜150万円です。** 当サイトで開業資金がわかる117本部の中央値（350万円）より低い一方、毎月の支払いや契約期間の形は本部ごとにばらばらです。

## ネット通販の市場

経済産業省の「令和6年度 電子商取引に関する市場調査」によると、2024年の日本国内の消費者向け電子商取引（BtoC-EC）の市場規模は26.1兆円で、前年の24.8兆円から5.1％増えました。物販系分野を対象に算出したEC化率は9.8％で、前年から0.4ポイント上がっています。

商品の分野別では、「食品、飲料、酒類」（3兆1,163億円）、「衣類・服装雑貨等」（2兆7,980億円）、「生活家電・AV機器・PC・周辺機器等」（2兆7,443億円）、「生活雑貨、家具、インテリア」（2兆5,616億円）の4つが2兆円を超えています。個人どうしの取引（CtoC-EC）の市場規模は2兆5,269億円と推計されています。

出典：[経済産業省「令和6年度電子商取引に関する市場調査の結果を取りまとめました」（2025年8月26日）](https://www.meti.go.jp/press/2025/08/20250826005/20250826005.html)

## 開業に必要な届出

個人で始める場合は、税務署に開業届を出します。

| 届出 | 提出先 | 期限 |
|---|---|---|
| 個人事業の開業届出書 | 納税地を所轄する税務署 | 事業を始めた年分の確定申告期限まで |
| 青色申告承認申請書（青色申告をする場合） | 同上 | 年の途中で開業した場合は、開業日から2か月以内 |

出典：[国税庁「個人事業の開業届出・廃業届出等手続」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/04.htm)／[国税庁「所得税の青色申告承認申請手続」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/09.htm)

このほか、扱う商品によって許可や届出が必要になります。物販で特に関係が深いのが、次の古物商許可です。

## 古物商許可がいる場合・いらない場合

古物営業法でいう「古物」は、一度使用された物品だけでなく、**使用されていない物品でも「使用のために取引されたもの」**を含みます（福島県警察本部「古物営業を営まれる方へ」）。つまり、一度お店で一般の人に売られた新品を仕入れて売る場合も、古物にあたることがあります。

熊本県警は、許可が必要な場合と必要ない場合を次のように例示しています。

| 古物商許可が必要 | 古物商許可は必要ない |
|---|---|
| 古物を買い取って販売する | 自分の物を販売する（自分で使っていた物、使うために買ったが未使用の物） |
| 買い取った古物を修理して販売する | 無償でもらった物を販売する |
| 買い取った古物のうち、使える部品を販売する | 相手から手数料をとって回収した物を販売する |
| 買い取った古物をレンタルする | 自分が売った相手から売った物を買い戻す |
| 古物を別の物と交換する | 自分が海外で購入した物を輸入して販売する |
| 上のことをインターネットなどで、非対面で行う | |

熊本県警は、これらは一例であり、詳しくは問い合わせるよう案内しています。申請先は主たる営業所の所在地を管轄する警察署で、手数料は19,000円です（警視庁・熊本県）。

出典：[熊本県「古物商許可申請手続き」](https://www.pref.kumamoto.jp/site/police/128250.html)／[福島県警察本部「古物営業を営まれる方へ」](https://www.police.pref.fukushima.jp/03.tetuduki/-seian/kobutu/itonamarerukatahe.pdf)／[警視庁「古物商許可申請」](https://www.keishicho.metro.tokyo.lg.jp/tetsuzuki/kobutsu/tetsuzuki/kyoka.html)

許可を受けた古物商がホームページで古物を売る場合は、**ホームページ上に「許可を受けた公安委員会名」「許可証番号」「氏名又は名称」を表示**しなければなりません。警視庁は、インターネットで古物を販売することは特定商取引法の「通信販売」にもあたると説明しています。

出典：[警視庁「古物商許可申請をされる方へ」](https://www.keishicho.metro.tokyo.lg.jp/tetsuzuki/kobutsu/kaisetsu/kobutsu_shinsei.html)

## 特定商取引法で決められた「通信販売」の表示

ネットショップでの販売は、特定商取引法の通信販売にあたります。消費者庁の特定商取引法ガイドでは、広告（ネットショップの商品ページなど）に表示する事項として、主に次のものを挙げています。

- 販売価格（送料についても表示が必要）
- 代金の支払時期、方法
- 商品の引渡時期
- 申込みの期間に関する定めがあるときは、その旨と内容
- 契約の申込みの撤回又は解除に関する事項（返品特約がある場合はその内容を含む）
- 事業者の氏名（名称）、住所、電話番号
- 法人がネットで広告する場合は、代表者又は通信販売に関する業務の責任者の氏名
- 販売価格・送料以外に購入者が負担する金銭があるときは、その内容と額
- 商品が契約の内容に適合しない場合の販売業者の責任についての定めがあるときは、その内容

あわせて、実際よりも著しく優良・有利だと誤認させる**誇大広告の禁止**や、あらかじめ承諾を得ていない相手への**電子メール広告の原則禁止**（オプトイン規制）も定められています。

出典：[消費者庁「通信販売｜特定商取引法ガイド」](https://www.no-trouble.caa.go.jp/what/mailorder/)

### 注文確定の直前の画面（最終確認画面）

2022年6月1日に施行された改正特定商取引法で、ネットの注文では、注文を確定する直前の「最終確認画面」に、原則として次の6項目を表示することになりました。

1. 分量
2. 販売価格・対価（送料を含む）
3. 支払時期及び支払方法
4. 引渡時期
5. 申込みの期間がある場合は、その旨と内容
6. 申込みの撤回・解除に関する事項

出典：[消費者庁取引対策課「令和3年特定商取引法・預託法等改正に係る令和4年6月1日施行に向けた事業者説明会」（令和4年3月、近畿経済産業局掲載）](https://www.kansai.meti.go.jp/4syokei/tokusyou/consumer_transaction_cms202_220322_01.pdf)

### 返品は「返品特約」の書き方しだい

通信販売では、商品を受け取った日から8日以内であれば、消費者は契約の申込みの撤回や解除ができると定められています。ただし、**事業者が広告であらかじめ返品についての特約を表示していた場合は、その特約によります。** 返品を受けるかどうか、受けるなら送料はどちらが負担するかを、商品ページと最終確認画面にはっきり書いておくことが大切です。

出典：[消費者庁「通信販売｜特定商取引法ガイド」](https://www.no-trouble.caa.go.jp/what/mailorder/)

## 売る場所の規約も確認する：無在庫出品は禁止のサイトがある

法律とは別に、モールやフリマアプリにはそれぞれ出品のルールがあります。たとえばメルカリの出品者ガイドラインは、「手元にある商品のみ出品可能です。ECサイトからの直送（直接購入者の住所に配送させること）、手元にない商品の出品は禁止しています」と定めています。

出典：[メルカリ「出品者ガイドライン」](https://help.jp.mercari.com/guide/articles/2015/)

物販系のフランチャイズ本部やサポートサービスの中には、在庫を持たずに注文が入ってから仕入れる「無在庫」型をうたうものがあります。**その仕組みが、実際に売る予定のモールやアプリの規約で認められているか**は、加盟前に本部へ確認し、売る場所の規約も自分で読んでおく必要があります。

当サイトに掲載している物販系の本部のうち、開業資金の金額を確認できた本部を並べると次のとおりです。

- 無在庫物販 UEC（32万円）：BMフランチャイズの掲載値です。公式ページには初期費用の数値の記載がなく（資料請求制）、「無在庫販売なので在庫リスクは無し！」と説明されています。
- システムでネットショップ運営【アクセス】（41万円）：BMフランチャイズの掲載値で、税区分の記載はありません。

輸出マスター（自己資金198万円以上の掲載あり）は、開業資金の総額を確認できていないため表から外しています。

4本部とも、当サイトで開業資金がわかる117本部の中央値（350万円）を下回り、117本部のうち150万円以下は34本部です。ただし物販では、本部に払うお金とは別に**商品の仕入れ代金**がかかります。無在庫型でも、注文が入ってから仕入れ代金を払う必要があります。表の金額に仕入れ資金が含まれているか、売上が入金される前に仕入れ代金をいくら立て替えることになるかは、本部に確認してください。

## 個人で始める場合と本部に加盟する場合

| | 個人で始める | 物販系の本部に加盟 |
|---|---|---|
| 本部への支払い | なし | 加盟金・月額の費用（本部による） |
| 商品選び・仕入れ先 | 自分で探す | 本部のシステムやノウハウを使える |

本部に加盟する場合も、古物商許可を誰の名義でとるのか、特定商取引法の表示に誰の氏名・住所を出すのかは、加盟前に確認しておきましょう。

## 「簡単に稼げる」物販サポートの勧誘に注意

国民生活センターは、「簡単に稼げる」とうたう副業の勧誘について、2023年10月27日に注意を呼びかけています。数千円のマニュアルを買ったあと、電話で約60万円のプランを勧められて契約したが収入はなく、事業者と連絡が取れなくなった事例などを紹介し、次のように助言しています。

- 「簡単に稼げる」「もうかる」ことを強調する広告やランキングサイトをうのみにしない
- 作業内容や利益が出る仕組みがよくわからなければ契約しない
- 少しでも不安に思ったら早めに消費生活センター等に相談する

出典：[国民生活センター「【20代特に注意！】簡単に稼げるという副業」（2023年10月27日）](https://www.kokusen.go.jp/news/data/n-20231027_1.html)

富山県の消費生活センターも、SNS広告から副業サイトに登録し、「簡単に儲かる転売ビジネスがあり、サポートをする」と電話で勧誘されて約10万円のサポート契約を結んだ相談事例を紹介しています。

出典：[くらしの安心ネットとやま（富山県消費生活センター）「転売ビジネス」の相談事例](https://www.pref.toyama.jp:443/documents/13666/210325tenbai_business.pdf)

フランチャイズ本部を比べるときも、**「どこから仕入れて、どこで売り、1件あたりいくら残るのか」**を自分で説明できるところまで聞いてから判断してください。

## 本部を選ぶときに確認したいこと

1. **仕入れと販売の仕組み**：どこから仕入れ、どのサイトで売るのか。無在庫で売る場合、そのサイトの規約で認められているか
2. **古物商許可の要否**：扱う商品が「古物」にあたるか。許可が必要なら、取得まで本部が案内してくれるか
3. **お金の中身**：開業資金に仕入れ資金が含まれるか。月額の費用はいくらで、割引期間が終わったあといくらになるか
4. **ショップの名義と表示**：特定商取引法の表示（氏名・住所・電話番号など）を誰の名前で出すのか。自宅住所を出したくない場合の扱い
5. **契約期間と解約**：自動更新の有無、途中でやめるときの違約金、やめたあとにショップやアカウントを使い続けられるか

金額や条件は変わることがあります。気になる本部は、資料請求や説明会で最新の内容を確認してください。
