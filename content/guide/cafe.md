カフェを個人で開くか、フランチャイズに加盟して開くかで、準備することもお金のかかり方も変わります。この記事では、開業前に押さえておきたい「市場」「許可と届出」「お金」を、公的機関の情報と、当サイトに掲載しているカフェ・喫茶の本部データで整理します。

## 結論：カフェ開業の要点

- **保健所の「飲食店営業」の許可と、食品衛生責任者の設置が必要です。** 以前の「喫茶店営業」の許可は、2021年6月1日から「飲食店営業」に統合されました。店で作った焼き菓子やパンを持ち帰りで売る場合は、菓子製造業の許可が別に必要になることがあります。
- **当サイトで開業資金を確認できたカフェ・喫茶の本部4件では、200万円から6,600万円まで幅があります。** 4件の金額はいずれもBMフランチャイズの掲載値で、本部の公式ページでは確認できていません。
- **ロイヤリティの形は本部ごとにばらばらです。** 掲載5本部のうち、売上の割合（3％）が2本部、月額固定が1本部、席数に応じた額が1本部、定額（金額未確認）が1本部でした。

## カフェ・喫茶店の市場

日本フードサービス協会などの推計では、2023年の「喫茶店」の市場規模は**1兆1,892億円**で、前年より19.9％増えました。2022年は9,922億円（前年比18.6％増）でした。

出典：[日本フードサービス協会・食の安全・安心財団（令和5年外食産業市場規模推計、令和6年9月）](https://jfnet.or.jp/files/2024-1-1.pdf)

一方、喫茶店の生活衛生同業組合の全国団体（全国喫茶飲食生活衛生同業組合連合会）が厚生労働省の会議に出した資料では、業界の課題として「大手チェーン店、コンビニとの競合激化」「困難な人材の確保」「経営基盤が脆弱、後継者不足もあり事業承継が困難」などが挙げられています。

出典：[全国喫茶飲食生活衛生同業組合連合会「喫茶店営業の現況について」（厚生労働省 掲載資料）](https://www.mhlw.go.jp/content/11130500/001036081.pdf)

市場は戻ってきていますが、コーヒーはチェーン店やコンビニでも手軽に買えます。加盟を考える本部が、どんな立地・客層・客単価を前提に収支を組んでいるかは確認しておきたい点です。

## 開業に必要な許可・届出

カフェの開業では、保健所・消防・税務署への手続きが必要です。夜にお酒を出す場合は警察への届出も加わります。

| 手続き | 提出先 | 内容・注意点 |
|---|---|---|
| 飲食店営業の許可 | 店舗を管轄する保健所 | 2021年6月1日から「喫茶店営業」は「飲食店営業」に統合。施設が基準に合い、工事が終わっていないと許可にならない。相模原市の例では、新規の申請手数料は16,000円 |
| 食品衛生責任者の設置 | （許可申請時に届け出る） | 許可・届出の対象となる施設には原則として設置が必要。調理師・栄養士・製菓衛生師などの免許があればなれる。ない場合は養成講習会を受講する |
| HACCPに沿った衛生管理 | — | 2021年6月1日から、原則すべての食品等事業者に義務付け |
| 防火管理者の選任 | 消防署 | 飲食店など不特定多数が出入りする建物で、建物全体の収容人員が30人以上の場合 |
| 消火器の設置 | — | 延べ面積150㎡未満の建物でも、こんろなど火を使う設備・器具を設けている飲食店は設置が必要（防火上有効な措置がある場合を除く） |
| 深夜における酒類提供飲食店営業の届出（該当する場合） | 警察署経由で公安委員会 | 午前0時〜午前6時に酒類を提供する場合。営業開始の10日前までに届け出る |
| 個人事業の開業届出書 | 納税地を所轄する税務署 | 事業を始めた年分の確定申告期限まで |
| 青色申告承認申請書（青色申告をする場合） | 同上 | 年の途中で開業した場合は、開業日から2か月以内 |

出典：[浜松市「食品衛生法改正による営業許可制度の見直しについて」](https://www.city.hamamatsu.shizuoka.jp/seiei/food/safy/kyokakaisei.html)／[相模原市「営業許可申請書」](https://www.city.sagamihara.kanagawa.jp/shinseisho_menu/seikatsu_eisei/1012001.html)／[愛知県「営業許可制度の見直し及び営業届出制度の創設について」](https://www.pref.aichi.jp/soshiki/eisei/kyoka-todokede-minaoshi.html)／[中央区「食品衛生責任者の資格はどうしたら取れますか」](https://www.city.chuo.lg.jp/a0030/faq/kenkouiryou/eisei/0005.html)／[浜松市消防局（防火管理者の案内）](https://www.city.hamamatsu.shizuoka.jp/hfdyobo/boukakanri.html)／[横浜市「飲食店を営業されている皆様へ」](https://www.city.yokohama.lg.jp/business/bunyabetsu/shobo-kyukyu/kanri/tatemono/insyokuten-syoukaki.html)／[高知県警察「深夜における酒類提供飲食店営業届出の手引き」](https://www.police.pref.kochi.lg.jp/docs/2023110800016/file_contents/R3_shinnyatebiki.pdf)／[国税庁「個人事業の開業届出・廃業届出等手続」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/04.htm)／[国税庁「所得税の青色申告承認申請手続」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/09.htm)

保健所の許可は、完成した店舗の施設検査を経て出ます。相模原市は「施設の工事着工前に、図面をお持ちになって、ご相談ください」と案内しています。手数料や施設基準の細かな内容は自治体ごとに決まっているため、出店先の保健所・消防署の案内を確認してください。

## 焼き菓子・コーヒー豆を持ち帰りで売るなら、別の許可・届出も確認

カフェでは、店内のメニューのほかに焼き菓子やコーヒー豆を持ち帰り用に売ることがあります。この場合、飲食店営業の許可だけでは足りないことがあります。

| 売りたいもの | 必要になる手続きの例 |
|---|---|
| 店で作った菓子・パン（ケーキ、クッキー、焼き菓子など）の持ち帰り販売 | 菓子製造業の許可。青森市の案内では、菓子・パンは店頭販売・出前でも卸販売でも菓子製造業の許可が必要とされている |
| コーヒー豆（焙煎して販売する場合など） | 営業許可は不要で「営業届」を出す（鹿児島市の案内）。容器包装して売る場合は食品表示が必要 |

出典：[青森市「飲食店営業許可施設のテイクアウト等について」](https://www.city.aomori.aomori.jp/_res/projects/default_project/_page_/001/002/130/inshoku_take_out.pdf)／[沖縄県「食品営業 よくある相談・問い合わせ」](https://www.pref.okinawa.jp/iryokenko/eiseiyakuji/1006591/1006664/1006666.html)／[鹿児島市「コーヒー豆、お茶などを作って販売したいのですが、どのような手続きをしたらよいですか」](https://www.city.kagoshima.lg.jp/faq-kenkofukushi/seiei-shoku/q14.html)

扱いは食品の種類と売り方で変わり、自治体によって細部も違います。物販を考えている場合は、図面の相談の段階で保健所に伝えておくと、許可の取り直しや設備の追加を避けやすくなります。フランチャイズでは、本部の商品を仕入れて売るのか、店で作るのかでも必要な手続きが変わるため、本部に確認してください。

## テイクアウトのコーヒーは消費税の税率が変わる

国税庁の「消費税の軽減税率制度に関するQ&A」では、店内飲食は標準税率（10％）、テイクアウト（持ち帰り）は軽減税率（8％）とされ、顧客の意思表示によって異なる税率が適用されるとしています。意思の確認は、「テイクアウトの場合はお申し出ください」と掲示するなど、営業の実態に応じた方法でよいとされています。

出典：[国税庁「消費税の軽減税率制度に関するQ&A」問121](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/pdf/qa/03-09.pdf)

持ち帰りのドリンクやお菓子の売上が多いカフェでは、レジや会計が2つの税率に対応しているかを、開店前に確かめておきたい点です。

## ロイヤリティは本部ごとに形が違う

当サイトに掲載しているカフェ・喫茶の5本部を、ロイヤリティの形で分けると次のとおりです。

| ロイヤリティの形 | 本部と公表値 |
|---|---|
| 売上の割合 | さかい珈琲店 総売上高の3％、髙木珈琲 3％ |
| 月額固定 | 京都利休の生わらび餅 月額固定5万円（月間仕入れ180kg未満だった月は発生しない） |
| 席数に応じた額 | コメダ珈琲店 1席あたり月額1,500円（消費税別）。公式の例では月額135,000円 |
| 定額（金額未確認） | 魔法のパンケーキ（定額である点のみ公式と一致。金額は確認できず） |

コメダ珈琲店の値は公式の加盟案内、そのほかの4本部はBMフランチャイズの掲載値です。

当サイトの飲食店（その他）の本部では、ロイヤリティは「売上の◯％」が19本部中11本部と中心でした（[飲食店フランチャイズの開業ガイド](/guide/restaurant/)）。カフェ・喫茶の5本部では、売上の割合は2本部だけで、固定額や席数に応じた額など、売上に連動しない形が多いのが特徴です。

売上に連動しない形は、売上が伸びても支払いは変わりませんが、売上が少ない月も同じ額を払います。席数に応じた形では、店を広くするほど毎月の支払いも増えます。**開業から数か月の売上見込みと、ロイヤリティ・家賃・人件費・原材料費を並べて、毎月の支払いが賄えるか**を計算しておくのが確実です。

## 個人とフランチャイズ、どちらで始める？

| | 個人で独立 | フランチャイズに加盟 |
|---|---|---|
| 営業許可・食品衛生責任者 | 必要 | 必要 |
| 初期費用 | 物件・内装・厨房設備・家具・食器が中心 | 加盟金・研修費などが加わる。保証金を求める本部もある |
| 毎月の支払い | なし | ロイヤリティ（形は本部による） |
| メニュー・店づくり | 自分で決める | 本部のメニュー・内装を使う。変えられる範囲は契約による |
| 豆・材料の仕入れ | 自分で探す | 本部の指定や供給があるか確認する |
| 集客 | 自分で集める | 本部のブランドや集客支援があるか確認する |

自分の店のコンセプトやコーヒーへのこだわりを形にしたい場合は個人で、メニュー・仕入れ・運営の仕組みを本部に頼りたい場合はフランチャイズで、という分け方が考えられます。

## 本部を選ぶときに確認したいこと

1. **開業資金に含まれるもの**：物件取得費・内装工事・厨房設備が入っているか、別途か。居抜きかスケルトンか、何席・何坪を想定した金額か
2. **ロイヤリティの形と条件**：売上の割合か、固定額か、席数に応じた額か。売上が少ない月の扱いや、保証金の有無
3. **仕入れとメニューの決まり**：コーヒー豆や材料を本部から仕入れる決まりがあるか、メニューや価格を変えられるか
4. **物販の許可**：焼き菓子や豆を持ち帰りで売る場合、どの許可・届出が必要で、本部がどこまで手伝うか
5. **法定開示書面**：中小小売商業振興法では、一定の要件を満たす本部に、事業の概要や契約の主な内容を契約前に書面で渡して説明することを義務付けています。書面を受け取り、収支モデルや解約の条件と照らして確認してください
6. **募集の対象・エリア・契約期間**：髙木珈琲は法人のみの募集、さかい珈琲店は関東1都6県を除く全国での募集です。契約期間の掲載値（BMフランチャイズ掲載値）は、コメダ珈琲店が10年、さかい珈琲店・髙木珈琲が5年、京都利休の生わらび餅が1年です

出典：[中小企業庁「特定連鎖化事業（フランチャイズ）について」](https://www.chusho.meti.go.jp/shogyo/shogyo/franchise.html)

金額や条件は変わることがあります。気になる本部は、資料請求や説明会で最新の内容を確認してください。
