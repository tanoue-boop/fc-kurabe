ラーメン店を個人で開くか、フランチャイズに加盟して開くかで、準備することもお金のかかり方も変わります。この記事では、開業前に押さえておきたい「市場」「許可と届出」「お金」を、公的機関の情報と、当サイトに掲載しているラーメンの本部8件のデータで整理します。

## 結論：ラーメンのフランチャイズ開業の要点

- **保健所の「飲食店営業」の許可と、食品衛生責任者の設置が必要です。** 店内で出す麺を自家製にするのは飲食店営業の範囲ですが、自家製麺を持ち帰りで売ったり系列店に卸したりする場合は「めん類製造業」の許可が別に必要になります。
- **当サイトに掲載しているラーメンの本部のうち、開業資金の総額を掲載している7本部では、360万円から1,895万円まで幅があります。** このほか、加盟時の初期費用（318万円・税込）だけを公表し、物件・工事費を含む総額は条件で変わるとしている本部が1件あります。
- **ロイヤリティの形は本部ごとにばらばらです。** 8本部のうち、売上の割合が3本部、月額の定額が2本部、坪数に応じた額が1本部、ロイヤリティなしが2本部でした。

## ラーメン店の市場

中小企業基盤整備機構のJ-Net21「ラーメン店」（2023年1月20日）では、平成28年経済センサスによるとラーメン店は全国に18,041店、市場規模はおよそ6,019億円と紹介されています。

同じページでは、ラーメン店開業の人気の理由として「比較的低資金で始められること」（10坪以下の小規模店でも開業できる、居抜き物件を活用できる）、「専門的な資格が不要であること」「店ごとのこだわりを反映させやすいこと」を挙げる一方、課題として「競合する店の数が多い」「原材料費の負担が大きい」を挙げています。

出典：[J-Net21（中小企業基盤整備機構）「ラーメン店」](https://j-net21.smrj.go.jp/startup/guide/restaurant/food08.html)

店の数が多く、原材料費の負担も大きい業種です。加盟を考える本部が、どんな立地・坪数・客単価を前提に収支を組んでいるか、スープや麺の仕入れ値がどう決まるかは確認しておきたい点です。

## 開業に必要な許可・届出

ラーメン店の開業では、保健所・消防・税務署への手続きが必要です。夜にお酒を出す場合は警察への届出も加わります。

| 手続き | 提出先 | 内容・注意点 |
|---|---|---|
| 飲食店営業の許可 | 店舗を管轄する保健所 | 施設が基準に合い、工事が終わっていないと許可にならない。申請手数料は自治体ごとに決まっており、相模原市の例では新規16,000円、福岡市の例では16,600円 |
| 食品衛生責任者の設置 | （許可申請時に届け出る） | 許可・届出の対象となる施設には原則として設置が必要。調理師・栄養士・製菓衛生師などの免許があればなれる。ない場合は養成講習会を受講する |
| HACCPに沿った衛生管理 | — | 2021年6月1日から、原則すべての食品等事業者に義務付け |
| 防火管理者の選任 | 消防署 | 飲食店など不特定多数が出入りする建物で、建物全体の収容人員が30人以上の場合 |
| 消火器の設置 | — | 延べ面積150㎡未満の建物でも、こんろなど火を使う設備・器具を設けている飲食店は設置が必要（防火上有効な措置がある場合を除く） |
| 深夜における酒類提供飲食店営業の届出（該当する場合） | 警察署経由で公安委員会 | 午前0時〜午前6時に酒類を提供する場合。営業開始の10日前までに届け出る |
| 個人事業の開業届出書 | 納税地を所轄する税務署 | 事業を始めた年分の確定申告期限まで |
| 青色申告承認申請書（青色申告をする場合） | 同上 | 年の途中で開業した場合は、開業日から2か月以内 |

出典：[相模原市「営業許可申請書」](https://www.city.sagamihara.kanagawa.jp/shinseisho_menu/seikatsu_eisei/1012001.html)／[福岡市「食品に関する営業を始める皆様へ～営業許可申請の手引き～」](https://www.city.fukuoka.lg.jp/hofuku/chuo-eisei/life/documents/kyokashinseitebiki.pdf)／[愛知県「営業許可制度の見直し及び営業届出制度の創設について」](https://www.pref.aichi.jp/soshiki/eisei/kyoka-todokede-minaoshi.html)／[中央区「食品衛生責任者の資格はどうしたら取れますか」](https://www.city.chuo.lg.jp/a0030/faq/kenkouiryou/eisei/0005.html)／[浜松市消防局（防火管理者の案内）](https://www.city.hamamatsu.shizuoka.jp/hfdyobo/boukakanri.html)／[横浜市「飲食店を営業されている皆様へ」](https://www.city.yokohama.lg.jp/business/bunyabetsu/shobo-kyukyu/kanri/tatemono/insyokuten-syoukaki.html)／[高知県警察「深夜における酒類提供飲食店営業届出の手引き」](https://www.police.pref.kochi.lg.jp/docs/2023110800016/file_contents/R3_shinnyatebiki.pdf)／[国税庁「個人事業の開業届出・廃業届出等手続」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/04.htm)／[国税庁「所得税の青色申告承認申請手続」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/09.htm)

保健所の許可は完成した店舗の施設検査を経て出るため、相模原市は「施設の工事着工前に、図面をお持ちになって、ご相談ください」と案内しています。手数料や施設基準の細かな内容は自治体ごとに決まっているため、出店先の保健所・消防署の案内を確認してください。

## 自家製麺を持ち帰りで売るなら「めん類製造業」の許可も

ラーメン店では、麺を店で打つことや、麺・スープをお土産用に売ることがあります。青森市の案内では、自家製めん（ラーメン等の生・ゆで・干麺）の扱いは次のように整理されています。

| 自家製麺の出し方 | 必要な許可 |
|---|---|
| 店内で調理して食事として出す | 飲食店営業（自家製麺の使用） |
| 店頭販売（テイクアウト）・出前 | めん類製造業 |
| 店以外の場所（系列店など）に卸して売る | めん類製造業 |

青森市は「菓子や自家製麺等の持ち帰り販売や、別の店（系列店舗等）に卸して販売する場合など、食品の種類と提供方法により、飲食店とは別の許可が必要な場合があります」としています。福岡市の手引きでは、めん類製造業の申請手数料は14,400円です。

出典：[青森市「飲食店営業許可施設のテイクアウト等について」](https://www.city.aomori.aomori.jp/_res/projects/default_project/_page_/001/002/130/inshoku_take_out.pdf)／[福岡市「食品に関する営業を始める皆様へ～営業許可申請の手引き～」](https://www.city.fukuoka.lg.jp/hofuku/chuo-eisei/life/documents/kyokashinseitebiki.pdf)

フランチャイズでは、麺を本部から仕入れるのか、店で作るのか、お土産ラーメンを売るのかで必要な手続きが変わります。物販を考えている場合は、図面の相談の段階で保健所に伝え、本部にもどこまで手伝ってもらえるかを確認してください。

## スープの油は下水に流せない：グリース阻集器の設置と清掃

豚骨や背脂を使うラーメン店では、厨房の排水に油が多く混じります。福岡市は、油脂を排出する場合はグリース阻集器（グリーストラップ）を設置し適切に管理するよう求めており、その根拠として「福岡市下水道条例施行規則第3条第2項」を挙げています。油を流すと「下水道管の詰まりや悪臭、害虫が発生し、周辺の方にも迷惑をかけてしまいます」とし、原因者が下水道管の清掃費用（事例として数十万円〜数百万円）や、逆流などで第三者に被害を与えた場合の損害賠償（事例として数百万円〜数千万円）を負担する場合があるとしています。

広島市は、グリース阻集器の管理の目安を次のように示しています。

| 頻度 | 作業 |
|---|---|
| 毎日1回 | バスケットの掃除 |
| 週に1回以上 | 油脂分の除去 |
| 月に1回以上 | 沈殿物の除去 |
| 2〜3か月に1回 | トラップ内部の掃除 |

取り除いた油などは「専門の廃棄物処理業者に処理を依頼してください」とされています。

出典：[福岡市「油脂類を公共下水道に流さないでください」](https://www.city.fukuoka.lg.jp/doro-gesuido/hozen/hp/rule/oil.html)／[広島市「グリース阻集器の設置と適正な管理のお願い」](https://www.city.hiroshima.lg.jp/site/gesuido/2743.html)

居抜き物件では、前の店のグリース阻集器の大きさや状態をそのまま使えるかも、内装工事の見積もりの前に確認しておきたい点です。清掃を業者に頼む場合は、その費用も毎月の支出に入れておきます。

## ロイヤリティは本部ごとに形が違う

当サイトに掲載しているラーメンの8本部を、ロイヤリティの形で分けると次のとおりです。

| ロイヤリティの形 | 本部と公表値 |
|---|---|
| 売上の割合 | らあめん花月嵐 月々の売上の5％（飲料代除く）、太陽のトマト麺 3％（法人向けの生業物語）／5％（個人向けの夢路物語）、ばり嗎 3％ |
| 月額の定額 | たんたんめんkai 5万円、麺屋あさひ堂 10万円／月（税別。月売上400万円超の場合は20万円） |
| 坪数に応じた額 | つけ麺まるや 坪数×5,000円＋システム使用料27,600円（固定）、営業開始月から |
| なし | 一竜（公式「ロイヤリティゼロ」）、フレンチラーメン（0円） |

らあめん花月嵐・太陽のトマト麺・一竜の値は公式の加盟案内、そのほかの5本部はBMフランチャイズの掲載値です。

当サイトの飲食店（その他）の本部では、ロイヤリティは「売上の◯％」が19本部中11本部と中心でした（[飲食店フランチャイズの開業ガイド](/guide/restaurant/)）。ラーメンの8本部では売上の割合は3本部で、定額・坪数に応じた額・ロイヤリティなしが合わせて5本部と、売上に連動しない形のほうが多くなっています。

ロイヤリティがない本部でも、麺・スープ・タレなどの仕入れを通じて本部にお金が入る仕組みのことがあります。**ロイヤリティの率や額だけでなく、本部から仕入れる食材の範囲と価格、原価率の見込みを合わせて**比べると、毎月の支払いの実態がつかみやすくなります。

## 個人とフランチャイズ、どちらで始める？

| | 個人で独立 | フランチャイズに加盟 |
|---|---|---|
| 営業許可・食品衛生責任者 | 必要 | 必要 |
| 初期費用 | 物件・内装・厨房設備が中心 | 加盟金・研修費などが加わる。保証金を求める本部もある |
| 毎月の支払い | なし | ロイヤリティ（形は本部による。なしの本部もある） |
| スープ・麺・メニュー | 自分で開発する | 本部のレシピ・食材を使う。変えられる範囲は契約による |
| 調理の習得 | 修業や独学 | 本部の研修。J-Net21も「フランチャイズ店では研修制度が整っている」と紹介 |
| 集客 | 自分で集める | 本部のブランドや集客支援があるか確認する |

自分の味を一から作りたい場合は個人で、レシピ・食材・運営の仕組みを本部に頼りたい場合はフランチャイズで、という分け方が考えられます。

## 本部を選ぶときに確認したいこと

1. **開業資金に含まれるもの**：物件取得費・内装工事・厨房設備が入っているか、別途か。何坪・何席・居抜きかスケルトンかを想定した金額か
2. **ロイヤリティと仕入れ**：売上の割合か、定額か、坪数に応じた額か。ロイヤリティがない場合は、本部から仕入れる食材の範囲と価格
3. **麺・スープの作り方と許可**：店で麺やスープを作るのか、本部から仕入れるのか。お土産用に売る場合にどの許可が必要か
4. **排水設備**：グリース阻集器の容量や清掃の方法・費用を、本部が物件選びの段階で見てくれるか
5. **店舗数と実績**：当サイトの掲載値では、たんたんめんkai・麺屋あさひ堂の店舗数は0です（BMフランチャイズ掲載値）。直営店の数や、加盟店の開業実績を確認する
6. **法定開示書面**：中小小売商業振興法では、一定の要件を満たす本部に、事業の概要や契約の主な内容を契約前に書面で渡して説明することを義務付けています。書面を受け取り、収支モデルや解約の条件と照らして確認してください
7. **契約期間**：掲載値では、つけ麺まるや・らあめん花月嵐・ばり嗎・一竜が5年、たんたんめんkai・麺屋あさひ堂が3年、太陽のトマト麺は初回が生業物語3年・夢路物語5年です

出典：[中小企業庁「特定連鎖化事業（フランチャイズ）について」](https://www.chusho.meti.go.jp/shogyo/shogyo/franchise.html)

金額や条件は変わることがあります。気になる本部は、資料請求や説明会で最新の内容を確認してください。
