飲食店のフランチャイズは、うどん・餃子・やきとり・カフェレストランなど業態が幅広く、開業資金も本部によって大きく違います。この記事では、開業前に押さえておきたい「市場」「許可と届出」「お金」を、公的機関の情報と各本部の公表値で整理します。ラーメン・カフェ・テイクアウトなどは別の記事でまとめる予定で、ここでは当サイトで「飲食店（その他）」に分類している本部を扱います。

## 結論：飲食店フランチャイズ開業の要点

- **保健所の「飲食店営業」の許可と、食品衛生責任者の設置が必要です。** 2021年6月からは、原則としてすべての食品等事業者にHACCPに沿った衛生管理も義務付けられています。許可は工事が終わった店舗の施設検査を経て出るため、工事の前に図面で保健所に相談しておくのが手順です。
- **当サイトで開業資金を確認できた飲食店の本部17件では、99万円から9,600万円まで幅があります。** 17件のうち9件は1,000万円を超えます。物件取得費や内装費が含まれるかどうかは本部によって違います。
- **ロイヤリティは「売上の◯％」が中心です。** 掲載19本部のうち11本部が売上の割合（1〜5％）で、固定額は3本部、ロイヤリティなしが1本部でした。

## 外食の市場

日本フードサービス協会などの推計では、2023年の外食産業の市場規模は**24兆1,512億円**で、前年より20.2％増えました（2019年比では8.1％減）。このうち「飲食店」の市場規模は**14兆1,313億円**（前年比18.6％増）です。農林水産省の資料（令和8年10月）でも、この2023年の推計が最新値として示されています。

## 開業に必要な許可・届出

飲食店の開業では、保健所・消防・税務署への手続きが必要です。お酒を深夜に出す業態では警察への届出も加わります。

| 手続き | 提出先 | 内容・注意点 |
|---|---|---|
| 飲食店営業の許可 | 店舗を管轄する保健所 | 施設が基準に合い、工事が終わっていないと許可にならない。相模原市の例では、新規の申請手数料は16,000円、許可は原則として施設検査の2日後（土日祝日等を除く） |
| 食品衛生責任者の設置 | （許可申請時に届け出る） | 許可・届出の対象となる施設には原則として設置が必要。調理師・栄養士・製菓衛生師などの免許があればなれる。ない場合は養成講習会を受講する |
| HACCPに沿った衛生管理 | — | 2021年6月1日から、原則すべての食品等事業者に義務付け |
| 防火管理者の選任 | 消防署 | 飲食店など不特定多数が出入りする建物で、建物全体の収容人員が30人以上の場合。延べ面積300㎡以上は甲種、それ未満は乙種の講習の対象 |
| 消火器の設置 | — | 2019年10月1日から、延べ面積150㎡未満の建物でも、こんろなど火を使う設備・器具を設けている飲食店は設置が必要（調理油加熱防止装置など防火上有効な措置がある場合を除く） |
| 深夜における酒類提供飲食店営業の届出（該当する場合） | 警察署経由で公安委員会 | 午前0時〜午前6時に酒類を提供する場合。営業開始の10日前までに届け出る。営業の常態として、通常主食と認められる食事を提供する店は不要 |
| 個人事業の開業届出書 | 納税地を所轄する税務署 | 事業を始めた年分の確定申告期限まで |
| 青色申告承認申請書（青色申告をする場合） | 同上 | 年の途中で開業した場合は、開業日から2か月以内 |

出典：[相模原市「営業許可申請書」](https://www.city.sagamihara.kanagawa.jp/shinseisho_menu/seikatsu_eisei/1012001.html)／[愛知県「営業許可制度の見直し及び営業届出制度の創設について」](https://www.pref.aichi.jp/soshiki/eisei/kyoka-todokede-minaoshi.html)／[中央区「食品衛生責任者の資格はどうしたら取れますか」](https://www.city.chuo.lg.jp/a0030/faq/kenkouiryou/eisei/0005.html)／[浜松市消防局（防火管理者の案内）](https://www.city.hamamatsu.shizuoka.jp/hfdyobo/boukakanri.html)／[横浜市「飲食店を営業されている皆様へ」](https://www.city.yokohama.lg.jp/business/bunyabetsu/shobo-kyukyu/kanri/tatemono/insyokuten-syoukaki.html)／[高知県警察「深夜における酒類提供飲食店営業届出の手引き」](https://www.police.pref.kochi.lg.jp/docs/2023110800016/file_contents/R3_shinnyatebiki.pdf)／[和歌山県警察（深夜における酒類提供飲食店営業の案内）](https://www.police.pref.wakayama.lg.jp/03_soudan/seian_todokede/documents/inshoku.pdf)／[国税庁「個人事業の開業届出・廃業届出等手続」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/04.htm)／[国税庁「所得税の青色申告承認申請手続」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/09.htm)

## 開店までの段取り：許可は「工事のあと」に出る

保健所の許可は、完成した店舗の施設検査を経て出ます。相模原市は「施設の工事着工前に、図面をお持ちになって、ご相談ください」と案内しています。工事が終わってから基準に合わないことがわかると、手直しで開店が遅れます。

そのため、開店までの流れはおおむね次の順番になります。

1. 本部との契約、物件の決定
2. 内装の図面を作り、工事の前に保健所へ相談する
3. 工事
4. 営業許可の申請と施設検査（食品衛生責任者を決めておく）
5. 許可が出てから営業開始（防火管理者・消火器などの消防の対応も済ませる）

フランチャイズでは、物件探しや内装工事を本部や本部の指定業者が手がけることがあります。**保健所・消防への相談や申請を本部がどこまで支援するか**は、契約前に確認しておきたい点です。

## テイクアウトを扱うなら消費税の税率に注意

国税庁の「消費税の軽減税率制度に関するQ&A」では、店内飲食は標準税率（10％）、テイクアウト（持ち帰り）は軽減税率（8％）とされ、顧客の意思表示によって異なる税率が適用されるとしています。意思の確認は、「テイクアウトの場合はお申し出ください」と掲示するなど、営業の実態に応じた方法でよいとされています。

出典：[国税庁「消費税の軽減税率制度に関するQ&A」問121](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/pdf/qa/03-09.pdf)

テイクアウトやデリバリーの売上が多い業態では、レジや会計の仕組みが2つの税率に対応しているかも、本部に確認しておくと安心です。

売上の割合で払う形は、売上が少ない月は支払いも少なくなりますが、売上が伸びるほど支払いも増えます。固定額は売上に関係なく毎月同じ額です。**開業から数か月の売上見込みと、ロイヤリティ・家賃・人件費・食材費を並べて、毎月の支払いが賄えるか**を計算しておくのが確実です。ロイヤリティのほかに、食材の仕入れを本部から行う決まりがあるかどうかも確認しておきたい点です。

## 個人とフランチャイズ、どちらで始める？

| | 個人で独立 | フランチャイズに加盟 |
|---|---|---|
| 営業許可・食品衛生責任者 | 必要 | 必要 |
| 初期費用 | 物件・内装・厨房設備・備品が中心 | 加盟金・研修費などが加わる（加盟金0円や免除の本部もある） |
| 毎月の支払い | なし | ロイヤリティ（売上の割合が中心） |
| メニュー・レシピ | 自分で作る | 本部のメニューを使う。自由に変えられる範囲は契約による |
| 食材の仕入れ | 自分で探す | 本部の指定や供給があるか確認する |
| 集客 | 自分で集める | 本部のブランドや集客支援があるか確認する |

自分の料理やお店の形がある場合は個人で、メニュー・仕入れ・運営の仕組みを本部に頼りたい場合はフランチャイズで、という分け方が考えられます。

## 本部を選ぶときに確認したいこと

1. **開業資金に含まれるもの**：物件取得費・内装工事・厨房設備が入っているか、別途か。居抜きかスケルトンか、何坪を想定した金額か
2. **ロイヤリティの形と条件**：売上の何％か、計算のもとが売上か純売上か、固定額の場合はいくらか
3. **仕入れと価格の決まり**：食材を本部から仕入れる決まりがあるか、メニューや価格を変えられるか
4. **許可・消防の支援**：保健所への事前相談や営業許可の申請、防火管理者の選任などを本部がどこまで手伝うか
5. **法定開示書面**：中小小売商業振興法では、一定の要件を満たす本部に、事業の概要や契約の主な内容を契約前に書面で渡して説明することを義務付けています。公正取引委員会のガイドラインも、契約前に開示することが望ましい項目を示しています。書面を受け取り、収支モデルや解約の条件と照らして確認してください
6. **募集の対象と契約期間**：法人のみ募集の本部もあります（PRONTO、DiPUNTO、大阪王将（のれんチャイズ））。契約期間を公表している本部の多くは3年か5年です
