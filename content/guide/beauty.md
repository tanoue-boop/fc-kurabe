美容室とエステサロンは、どちらも「美容」のお店ですが、開業に必要な資格や手続きは大きく違います。美容室は美容師法にもとづく届出と検査が必要で、エステは特別な許認可がない代わりに、医師でなければできない施術や、コース契約に関する法律のルールがあります。この記事では、開業前に押さえておきたい「市場」「資格と届出」「法規制」「お金」を、公的機関の情報と、当サイトに掲載している理容・美容の本部のデータで整理します。

## 結論：美容室・エステサロン開業の要点

- **美容室は、美容師免許を持つ人が、保健所の検査を受けた「美容所」で施術するのが前提です。** 美容師が常時2人以上いるお店は、管理美容師も置く必要があります。まつ毛エクステンションも美容所で美容師が施術するものとされています。
- **エステは許認可が要りませんが、レーザー脱毛などは医師でなければできません。** 1か月を超え5万円を超えるコース契約は特定商取引法の対象になり、クーリング・オフや中途解約のルールが適用されます。
- **当サイトで開業資金を確認できたサロン系の5本部では、150万円から600万円まで幅があります。** ロイヤリティは、月額の定額が1本部、売上の10％が2本部、掲載値なしが2本部です。

## 美容室・エステの市場

矢野経済研究所によると、理容室・美容室を合わせた理美容サロンの市場規模は、2025年度が2兆1,030億円（前年度比99.0％）で、前年度を下回ったのは2020年度以来です。2026年度は2兆1,002億円（前年度比99.9％）、うち美容サロン市場は1兆5,100億円と予測されています。

エステティックサロンの市場規模は、2025年度が2,797億円（前年度比92.1％）の見込みで、2026年度は2,803億円（前年度比100.2％）と予測されています。

出典：[矢野経済研究所「理美容サロン市場に関する調査を実施（2026年）」（2026年8月6日）](https://www.yano.co.jp/press-release/show/press_id/4150)／[矢野経済研究所「エステティックサロン市場に関する調査を実施（2026年）」（2026年5月8日）](https://www.yano.co.jp/press-release/show/press_id/4044)

お店の数は増えています。厚生労働省によると、2024年3月末の美容所数は27万4,070施設（前年度比1.5％増）、従業美容師数は57万9,768人（前年より7,958人増）です。市場規模が前年度を下回る一方で、施設の数は増えています。

出典：[厚生労働省「美容業概要」（衛生行政報告例による）](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/kenkou/seikatsu-eisei/seikatsu-eisei03/06.html)

## 美容室（美容所）を開くときの資格と届出

### 美容師免許と管理美容師

美容室で施術するには美容師免許が必要です。さらに、東京都は「美容師である従業員の数が常時2人以上いる美容所の開設者は、管理者を置かなくてはならない」としています。管理美容師になるには、美容師免許を受けた後3年以上美容の業務に従事し、都道府県知事が指定した講習会を修了する必要があります。

出典：[東京都保健医療局「管理理容師・管理美容師について」](https://www.hokeniryo.metro.tokyo.lg.jp/kankyo/shikaku/riyo/16.html)

### 保健所への開設届と検査

美容所を開くときは、保健所に開設届を出し、施設の検査を受けて確認を得てから開店します。東京都内の保健所の手引きでは、主な基準と費用は次のとおりです。

| 項目 | 内容（東京都内の保健所の例） |
|---|---|
| 届出の時期 | 施設検査までの日数に余裕をもって提出（江戸川区は検査の14日前まで） |
| 検査手数料 | 町田市・世田谷区は24,000円、江戸川区は24,050円 |
| 作業室の広さ | 13㎡以上（内法で算定） |
| 美容いすの台数 | 13㎡で6台まで。1台増やすごとに3㎡以上を加える |
| 主な提出書類 | 開設届、構造設備の概要、平面図、従業者名簿、美容師免許証、医師の診断書（結核・伝染性皮膚疾患でないことがわかるもの）、管理美容師の講習修了証（美容師が複数いる場合） |

基準や手数料は自治体ごとに決まっています。町田市の手引きでも、書類を出す前に保健所へ事前相談する流れになっているので、物件や内装を決める前に出店先の保健所に確認してください。

出典：[町田市保健所「美容所のてびき」（2026年5月）](https://www.city.machida.tokyo.jp/iryo/hokenjo/kankyou/riyousyo_biyousyo/biyou.files/biyou_tebiki_202605.pdf)／[世田谷保健所「美容所のてびき」（令和5年12月）](https://www.city.setagaya.lg.jp/documents/3227/tebiki.pdf)／[江戸川保健所「美容所のてびき」（令和5年12月13日現在）](https://www.city.edogawa.tokyo.jp/documents/8026/biyoujo_guide_edogawa.pdf)

### まつ毛エクステンションも美容所・美容師が必要

広島市は、営業者向けに「まつ毛エクステンションは、美容行為に該当し、美容所で美容師が施術しなければなりません」と案内しています。エステサロンのメニューにまつ毛エクステンションを加える場合も、美容所の届出と美容師が必要になります。

出典：[広島市「まつ毛エクステンションによる健康被害」](https://www.city.hiroshima.lg.jp/business/seikatsu-eisei/1026699/1013530.html)

## エステサロンを開くときに気を付けたい法規制

### 許認可は要らない

中小機構のJ-Net21は、エステティックサロンについて「法に基づく業種ではないため、特別な許認可を得る必要ない」としています。ただし、個人で始める場合も税務署への開業届は必要です（届出の期限は、事業を始めた年分の確定申告期限まで）。

出典：[J-Net21「エステティックサロン」](https://j-net21.smrj.go.jp/startup/guide/service/service12.html)／[国税庁「個人事業の開業届出・廃業届出等手続」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/04.htm)

### 医師でなければできない施術がある

厚生労働省の通知「医師免許を有しない者による脱毛行為等の取扱いについて」（平成13年11月8日）は、次の行為を医師免許のない人が業として行えば医師法第17条に違反するとしています。

- 用いる機器が医療用であるか否かを問わず、レーザー光線などの強力なエネルギーを有する光線を毛根部分に照射し、毛乳頭、皮脂腺開口部等を破壊する行為
- 針先に色素を付けながら、皮膚の表面に墨等の色素を入れる行為（いわゆるアートメイク）
- 酸等の化学薬品を皮膚に塗布して、しわ、しみ等に対して表皮剥離を行う行為

その後も、アートメイク（令和5年7月3日）や高密度焦点式超音波（HIFU）を用いた施術（令和6年6月7日）について、医師法上の取り扱いを示す通知が出ています。本部が用意するメニューや機器が、こうした線引きにかからないかは、加盟前に確認しておきたい点です。

出典：[厚生労働省医政局医事課長通知（平成13年11月8日 医政医発第105号、那覇市掲載）](https://www.city.naha.okinawa.jp/_res/projects/default_project/_page_/001/008/817/h131108_105.pdf)／[千葉県「美容医療に関する通知」](https://www.pref.chiba.lg.jp/iryou/sidou/biyouiryou.html)

### コース契約は特定商取引法の対象

エステの回数券・コース契約は、契約期間が1か月を超え、かつ契約金額が5万円を超えると、特定商取引法の「特定継続的役務提供」に当たります。事業者には法律で定められた書面を渡す義務があり、お客さまの側には次の権利があります。

| 項目 | 内容 |
|---|---|
| クーリング・オフ | 契約書面を受け取ってから8日以内 |
| 中途解約（サービス提供前） | 事業者が請求できるのは2万円まで |
| 中途解約（サービス提供後） | 提供したサービスの対価＋「2万円」か「契約残額の10％」の低いほうまで |

前払いのコース契約で売上を立てる場合は、途中解約による返金が出ることも見込んで資金繰りを考える必要があります。フランチャイズでは、契約書面のひな形を本部が用意しているかも確認しておきたい点です。

出典：[新潟県消費生活センター「エステティックサービスのトラブル」](https://www.pref.niigata.lg.jp/sec/shohiseikatsu/1356869965857.html)／[京都府消費生活安全センター「『エステ』『語学教室』など継続的サービスの中途解約について」](https://www.pref.kyoto.jp/shohise/15400050.html)

### 鍼灸院・整骨院の形は国家資格が必要

当サイトの「理容・美容」には、鍼灸院や整骨院の形の本部も含まれています。長野県は「医師以外の方が、あん摩、マッサージ、指圧、はり、きゅう及び柔道整復を業として行なおうとする場合には、それぞれの法律により免許を受けなければなりません」としています。東京都は、施術所を開設した人は開設後10日以内に保健所へ届け出るよう案内しています。

出典：[長野県「あん摩マッサージ指圧、はり、きゅう及び柔道整復について」](https://www.pref.nagano.lg.jp/doctor/kenko/doctor/hoken/massage.html)／[東京都保健医療局「あん摩マッサージ指圧・はり・きゅう、柔道整復施術所」](https://www.hokeniryo.metro.tokyo.lg.jp/iryo/shikaku/anmamassa-jisiatuharikyuujyuudou.html)

## 毎月の費用・ロイヤリティ

5本部のロイヤリティの掲載値は次のとおりです。

| 本部 | ロイヤリティ（掲載値） | 契約期間 |
|---|---|---|
| 小顔専門店BUPURA | 11万円／月（税込） | 3年 |
| 睡眠改善鍼灸院NEL | 売上の10％（初年度のみ減額キャンペーンあり） | 3年間 |
| 次世代型無人ホワイトニングサロンHAKU | 売上の10％ | 2年（その後同条件で自動更新） |
| アイブロウサロン＆α | 掲載値なし | 2年 |
| 駅前整体整骨院 | 掲載値なし | 3年 |

月額の定額が1本部、売上の割合が2本部、掲載値なしが2本部です。定額制は売上が少ない月も同じ額がかかり、売上の割合で払う形は売上に応じて支払いが増えます。BUPURAの月11万円は、年間にすると132万円（税込）です。

契約期間は5本部とも2〜3年です。更新の条件や更新料、契約満了前にやめるときの扱いもあわせて確認してください。

## 個人とフランチャイズ、どちらで始める？

| | 個人で開業 | フランチャイズに加盟 |
|---|---|---|
| 初期費用 | 物件・内装・機器が中心 | 加盟金などが加わる |
| 毎月の支払い | なし | ロイヤリティ（定額・売上の割合など） |
| メニュー・技術 | 自分で決め、自分で身に付ける | 本部のメニューと研修を使う |
| 集客 | 自分で集める | 本部のブランドや集客の仕組みを使える |

美容室は美容師免許が前提のため、美容師として経験を積んだ人の独立が中心です。厚生労働省の調査（平成27年度）をもとにしたJ-Net21の解説では、美容業の施設の約88.7％が個人経営とされています。フランチャイズでは本部のメニューや研修、集客の仕組みを使えますが、その分ロイヤリティなどの支払いが契約期間中続きます。

出典：[J-Net21「美容室」](https://j-net21.smrj.go.jp/startup/guide/service/service13.html)

## 本部を選ぶときに確認したいこと

1. **必要な資格**：美容師免許やはり師・きゅう師・柔道整復師の免許が要るメニューか、誰が施術するのか
2. **メニューと機器の扱い**：医師法の線引きにかかる施術や機器がないか
3. **開業資金に含まれるもの**：物件取得費・内装・機器・研修がどこまで入っているか
4. **毎月の支払い**：ロイヤリティのほか、システム料・広告分担金・機器のリース料などがないか
5. **コース契約の運用**：特定商取引法の書面のひな形や、中途解約・返金の対応を本部が用意しているか
6. **契約期間と更新・解約の条件**：2〜3年の契約が多いため、更新料や途中でやめるときの違約金を確認

金額や条件は変わることがあります。気になる本部は、資料請求や説明会で最新の内容を確認してください。
