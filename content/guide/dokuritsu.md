会社勤めから独立して事業を始める方法は、大きく「個人で一から始める」と「フランチャイズ本部に加盟する」の2つです。この記事では、公的機関の調査と当サイトに掲載している本部の公表値をもとに、どちらで始めるかを考えるための材料をまとめます。業種ごとの許認可や本部の比較は、業種別の開業ガイドで詳しく扱っています。

## 結論：独立開業の要点

- **独立した人の開業費用は、平均975万円・中央値600万円です**（日本政策金融公庫の2025年度調査）。資金の約7割は金融機関などからの借り入れで、自己資金は平均279万円でした。
- **フランチャイズ本部の開業資金は、業種によって大きく違います。** 当サイトで開業資金を確認できた117本部の中央値は350万円ですが、生活サービスやビジネス系は100万円台、飲食や学習塾は600万円台が中心です。
- **加盟する場合は、契約前に本部が出す書面を必ず確認します。** ロイヤリティの額と計算方法、契約期間と中途解約の条件などは、公正取引委員会が「開示が望ましい」としている項目です。

## 独立開業した人のデータ

日本政策金融公庫の「2025年度新規開業実態調査」は、同公庫の融資を受けて開業した企業（融資時点で開業後1年以内）を対象にした調査です（回答2,165社、2025年8月時点）。

| 項目 | 調査の結果 |
|---|---|
| 開業時の平均年齢 | 43.9歳（調査開始以来最も高い） |
| 開業直前の職業 | 「正社員・正職員（管理職）」41.1％、「正社員・正職員（管理職以外）」31.0％ |
| 開業費用 | 平均値975万円、中央値600万円。「250万円未満」20.1％、「250万〜500万円未満」21.7％ |
| 資金調達額 | 平均1,219万円（金融機関等からの借り入れ 平均827万円・67.9％、自己資金 平均279万円・22.9％） |
| 採算状況 | 「黒字基調」67.0％、「赤字基調」33.0％ |
| 開業時に苦労したこと（上位3つ） | 「資金繰り、資金調達」56.9％、「顧客・販路の開拓」49.9％、「財務・税務・法務に関する知識の不足」36.4％ |

開業直前に正社員・正職員だった人が7割強を占め、開業費用は500万円未満が4割以上を占めます。一方で、開業時に苦労したことの上位は「資金」と「お客さんの集め方」でした。この2つをどう手当てするかが、個人で始めるか、本部に加盟するかを考えるときの軸になります。

出典：[日本政策金融公庫「2025年度新規開業実態調査」（2025年12月5日）](https://www.jfc.go.jp/n/findings/pdf/kaigyo_251205_1.pdf)／[同 概要](https://www.jfc.go.jp/n/findings/pdf/topics_251205.pdf)

フランチャイズで開業する場の規模としては、日本フランチャイズチェーン協会の2024年度の統計で、チェーン数1,291、店舗数25万4,478店、売上高29兆2,825億円（前年度比3.6％増）と報じられています。

出典：[日本食糧新聞「24年度のFC売上高 4年連続増で29兆円超」（2026年1月16日）](https://news.nissyoku.co.jp/news/yamamotoh20251225091206919)

## 個人で始めるか、フランチャイズに加盟するか

| | 個人で始める | フランチャイズに加盟する |
|---|---|---|
| 初期費用 | 店舗・設備・広告など、自分で決めて用意する | 加盟金・研修費などが加わる（本部ごとに公表） |
| 毎月の支払い | 本部への支払いはない | ロイヤリティ（売上の割合・定額・なし など本部による） |
| 仕事のやり方 | 自分で決める | 本部のマニュアルや研修に沿う |
| 集客 | 自分で集める | 本部の屋号や集客の仕組みを使える |
| 契約の縛り | なし | 契約期間・中途解約・競業の制限などの条件がある |

公庫の調査で苦労したことの上位だった「資金」と「顧客・販路の開拓」のうち、本部に加盟して補えるのは主に後者です。そのぶん、ロイヤリティと契約の条件を受け入れることになります。経験や顧客のあてがある業種なら個人で、業種が未経験で集客の手段もない場合は本部の仕組みを使う、というのが比べ方の基本です。

## ロイヤリティの形は本部によってさまざま

掲載152本部のロイヤリティを、公表されている形で分けると次のとおりです。

| ロイヤリティの形 | 本部数 | 公表値の中央値 |
|---|---|---|
| 売上の割合（◯％） | 43 | 6％（最も多いのは3％で12本部） |
| 月の定額 | 39 | 月5万5,000円（税込・税抜が混在） |
| なし | 21 | ― |
| 割合と定額の組み合わせ | 8 | ― |
| 条件により変わる | 2 | ― |
| 公表なし・確認できず | 39 | ― |

業種によって傾向があり、教育・スクールは売上の割合（20本部中13）、リペア・リフォーム・住宅は月の定額（12本部中8）、ビジネス・その他サービスは「なし」（30本部中10）が多くなっています。定額制は売上が少ない月も同じ額がかかるため、開業直後の数か月分を運転資金として見ておく必要があります（[1人で開業できるフランチャイズ](/tag/hitori/)でも扱っています）。

## 独立開業に必要な手続き

### 個人事業として始める場合

| 届出 | 提出先 | 期限 |
|---|---|---|
| 個人事業の開業届出書 | 納税地を所轄する税務署 | 事業を始めた年分の確定申告期限まで |
| 青色申告承認申請書（青色申告をする場合） | 同上 | 年の途中で開業した場合は、開業日から2か月以内 |

出典：[国税庁「個人事業の開業届出・廃業届出等手続」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/04.htm)／[国税庁「所得税の青色申告承認申請手続」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/09.htm)

### 会社（法人）をつくって始める場合

設立登記のあと、税務署に「法人設立届出書」を出します。提出時期は「法人設立の日（設立登記の日）以後2月以内」、提出先は納税地の所轄税務署長です。

出典：[国税庁「内国普通法人等の設立の届出」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/hojin/annai/1554_2.htm)

### 会社を辞めたときの年金

会社員（厚生年金）から自営業になると、国民年金の第1号被保険者への切り替えが必要です。日本年金機構は、手続き先を「住所地の市区役所または町村役場」、期限を「退職日の翌日から14日以内」としています。

出典：[日本年金機構「国民年金に加入するための手続き」](https://www.nenkin.go.jp/service/kokunen/kanyu/20140710-04.html)

## 開業資金の集め方

公庫の調査では、資金調達額の67.9％が金融機関等からの借り入れでした。創業時に使われる代表的な制度が、日本政策金融公庫の「新規開業・スタートアップ支援資金」です。新たに事業を始める人や、事業開始後おおむね7年以内の人が使える融資制度で、融資限度額は7,200万円、返済期間は設備資金が20年以内、運転資金が10年以内（いずれも据置期間5年以内を含む）とされています。

出典：[日本政策金融公庫「新規開業・スタートアップ支援資金」](https://www.jfc.go.jp/n/finance/search/01_sinkikaigyou_m.html)

開業資金を抑えたい場合は、[低資金で開業できるフランチャイズ](/tag/teishikin/)や、会社に勤めながら始められる[副業から始められるフランチャイズ](/tag/fukugyo/)も参考にしてください。

## フランチャイズに加盟する前に確認すること

### 契約前の書面交付と、開示が望ましい項目

中小企業庁によると、中小小売商業振興法は、小売業のフランチャイズのうち「特定連鎖化事業」を行う本部に対し、「本部事業者の事業概要や契約の主な内容等」についての情報を、加盟しようとする人に「契約締結前に書面で交付し、説明すること」を義務づけています。

また、公正取引委員会の「フランチャイズ・システムに関する独占禁止法上の考え方」（令和3年4月28日改正）は、すべての業種のフランチャイズについて、本部が契約前に開示することが望ましい項目を示しています。主なものは次のとおりです。

1. 商品などの供給条件（仕入先の推奨制度など）
2. 経営指導の内容・方法・回数・費用負担
3. 加盟時に払うお金の性質・金額と、返還の有無・条件
4. ロイヤリティの額・算定方法・徴収の時期と方法
5. 本部との決済の仕組み、本部による融資の利率
6. 損失の補償や、経営不振になったときの支援の有無
7. 契約期間と、更新・解除・中途解約の条件・手続き
8. 加盟店の近くに、本部や他の加盟店が同じような店を出すことがあるか

本部が予想売上や予想収益を示す場合は、「類似した環境にある既存店舗の実績等根拠ある事実，合理的な算定方法等に基づくことが必要」とされています。説明会や面談で数字を見せられたときは、その根拠を聞いてください。

出典：[中小企業庁「特定連鎖化事業（フランチャイズ）について」](https://www.chusho.meti.go.jp/shogyo/shogyo/franchise.html)／[公正取引委員会「フランチャイズ・システムに関する独占禁止法上の考え方」](https://www.jftc.go.jp/dk/guideline/unyoukijun/franchise.html)

### 本部を比べるときのポイント

1. **開業資金に含まれるもの**：物件の取得費や賃料、車両、研修費がどこまで入っているか
2. **毎月の支払い**：ロイヤリティのほか、システム料・広告分担金などがないか
3. **お客さんの集め方**：本部が集客や案件の紹介をするのか、自分で集めるのか
4. **契約期間とやめるときの条件**：中途解約の違約金、契約終了後に同じ業種で営業できない期間（競業の制限）の有無
