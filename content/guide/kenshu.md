フランチャイズの研修について、多くの解説記事は「開業前研修と開業後研修の違い」「座学と店舗実習」「期間の目安」を扱っています。この記事では、**各本部が研修費をどう書いているか**を当サイトのデータで集計し、そのうえで法令と業界団体の資料に沿って、研修について確かめることを整理します。開業資金全体の内訳と融資は[フランチャイズの開業資金と融資](/guide/funding/)、加盟金の相場は[加盟金・保証金の相場](/guide/kameikin/)で扱っています。

## 結論：フランチャイズの研修の要点

- **研修費の書き方は本部によってばらばらです。** 当サイト掲載152本部のうち、研修費の記載があったのは34本部でした。研修費を金額で示していたのは21本部で、残りは「加盟金・初期費用に含む」が3本部、「無料・研修費なし」が3本部、研修の日数だけで金額の記載がないものが7本部です。
- **金額がわかる21本部では、11万円から173.8万円まで幅があります。** 中央値は50万円です（税込・税抜が混ざっています）。ハウスクリーニングや出張買取のように店舗を持たない業態では、研修費が開業資金の1〜4割台を占める本部がありました。
- **「1名あたり」「宿泊費は別」の本部があります。** 金額が1名あたり、または対象人数つきで書かれていた本部が5、宿泊寮費を別としていた本部が2ありました。何人が研修を受けるか、交通費や宿泊費を誰が払うかで、実際の負担は変わります。

## 研修の期間と内容：業界団体の説明

日本フランチャイズチェーン協会（JFA）の用語集は、「開業前研修費」を「開業する前に加盟店が本部の店舗、研修施設などを利用して研修を行う費用のこと。」と説明しています。同じ項目で、研修について次のように書いています。

- 「開業時研修は座学とオペレーション指導に分かれる。」座学は本部か研修施設で、オペレーション指導は直営店舗を使うことが多いとしています。
- 「研修期間は、サービスＦＣで一週間以内に終了する場合が多い。」「飲食業では１か月～２か月等長期にわたることもある。」
- 「開業前研修はオーナー研修と店長研修に分かれている場合がある。」
- 「研修に際しての交通費や宿泊費の実費は、加盟店が負担するのが大半である。」
- 「この研修費は加盟金に含むケースも含まないケースもあるので、契約時の確認が必要である。」

出典：[日本フランチャイズチェーン協会「フランチャイズ用語集 か行」（開業前研修費・加盟金）](https://www.jfa-fc.or.jp/particle/3617.html)

## 研修について、本部が書面に書くこと

### 中小小売商業振興法：研修の有無と内容

小売業のフランチャイズのうち中小小売商業振興法の対象となる本部は、契約を結ぶ前に、事業の概要や契約の主な内容を書いた書面を渡して説明する義務があります。同法の施行規則第十一条は、この書面に少なくとも書くべき内容を表で定めています。研修に関係するのは次の行です。

| 法が定める事項 | 施行規則が求める記載（原文） |
|---|---|
| 三　経営の指導に関する事項 | イ　加盟に際しての研修又は講習会の開催の有無 |
| | ロ　加盟に際して研修又は講習会が行われるときは、その内容 |
| | ハ　加盟者に対する継続的な経営指導の方法及びその実施回数 |
| 一　加盟に際し徴収する加盟金、保証金その他の金銭に関する事項 | イ　徴収する金銭の額又は算定方法 |
| | ロ　加盟金、保証金、備品代その他の徴収する金銭の性質 |
| | ハ　徴収の時期 |
| | ニ　徴収の方法 |
| | ホ　当該金銭の返還の有無及びその条件 |

研修の中身は「三」に、研修費として払うお金は「一」に当たります。研修費を別に払う本部なら、その額、何の対価か、いつ・どう払うか、返ってくるかどうかを書面で確かめられます。

出典：[e-Gov法令検索「中小小売商業振興法施行規則」（昭和四十八年通商産業省令第百号）第十一条](https://laws.e-gov.go.jp/law/348M50000400100)／[中小企業庁「特定連鎖化事業（フランチャイズ）について」](https://www.chusho.meti.go.jp/shogyo/shogyo/franchise.html)

### 公正取引委員会のガイドライン：指導の費用負担

業種を問わず、公正取引委員会の「フランチャイズ・システムに関する独占禁止法上の考え方」は、加盟者の募集のときに本部が開示することが望ましい事項として、「加盟者に対する事業活動上の指導の内容，方法，回数，費用負担に関する事項」と「加盟に際して徴収する金銭の性質，金額，その返還の有無及び返還の条件」を挙げています。小売業以外の本部でも、研修の内容と費用は聞いてよい項目です。説明会での聞き方は[フランチャイズ説明会で聞くこと](/guide/setsumeikai/)にまとめています。

出典：[公正取引委員会「フランチャイズ・システムに関する独占禁止法上の考え方」](https://www.jftc.go.jp/dk/guideline/unyoukijun/franchise.html)

### 金額がわかる21本部の分布

研修費を金額で示していた21本部（上の表の1・2段目と、加盟金の内訳に金額があるジェリーズポップコーン）を金額で分けると、次のとおりです。税込・税抜が混ざっているため、目安として見てください。

| 研修費 | 本部数 |
|---|---|
| 30万円未満 | 5 |
| 30万円以上50万円未満 | 5 |
| 50万円以上100万円未満 | 9 |
| 100万円以上 | 2 |

金額として最も低いのは一竜の1名あたり110,000円（税込）です（山下本気うどんは1名あたり100千円ですが、2名分の200千円で数えています）。最も高いのはおそうじ革命の開業前研修費1,738,000円（税込み）で、中央値は50万円でした。100万円以上の2本部はどちらもハウスクリーニングで、おそうじ本舗の初期研修開業準備費1,000,000円（税抜）には「新規加盟店研修費・HP制作費」が含まれています。

税区分は、研修費の記載か同じページの注記で税込とわかったものが5本部、税抜・税別が7本部、どちらも書かれていなかったものが9本部でした。比べるときは、すべて同じ税区分にそろえて聞き直します。

## 研修費の「条件」：人数・宿泊費・研修中の収入

金額だけを並べると見落としやすいのが、研修費の条件です。当サイトのデータでは、次のような書き方がありました。

- **1名あたり・人数つき（5本部）**：山下本気うどん「実稼働研修 30日間×2名 1名あたり＠100千円」、大阪王将「1名35万円 宿泊寮費別途」、太陽のトマト麺「1名25万円、宿泊寮費別途」＋開業前研修費20万円、一竜「1名あたり：110,000円（2人目以降は、追加1名につき55,000円）（税込）」、珈琲所コメダ珈琲店「3名様を対象とし約3ヶ月間の研修」500,000円（消費税別）。
- **宿泊寮費が別（2本部）**：大阪王将・太陽のトマト麺。JFAの説明のとおり、交通費や宿泊費は加盟者が負担する前提で見積もっておく必要があります。
- **研修中に支給がある（1本部）**：かさねやは、研修費用なしで「3ヶ月の間、月30万円を支給する既存店での研修(関東・1名の場合)」としています。
- **研修費とは別の名目の指導料（3本部）**：もみの匠「オープン前準備指導料 660,000円(税込)、オープン後1か月指導原価 660,000円(税込)」、WORLDREPAIR「技術研修費 275,000円（税込）／営業支援費 275,000円（税込）」、R Baker「開店支援費：マザー60万円、サテライトA 28万円、サテライトB 14万円」。
- **追加の研修は別料金（1本部）**：フレンチラーメン「（追加研修）→ 別途お見積り」。

夫婦や家族、店長候補と一緒に研修を受ける場合は、1名あたりの金額に人数をかけ、宿泊費・交通費を足した額が実際の負担になります。研修が1か月以上続く本部では、その間の生活費も開業前の資金として見ておく必要があります（[開業資金と融資](/guide/funding/)）。

## 研修について本部に確かめること

1. **研修の有無・内容・日数・場所**：座学と店舗での実習がそれぞれ何日か。オーナーだけか、店長やスタッフも受けるか
2. **研修費の金額と税区分**：税込か税抜か。1名あたりか、何名分か。2人目以降はいくらか
3. **開業資金・加盟金に含まれるか**：公表の開業資金に研修費が入っているか。加盟金の内訳か、別に払うか
4. **交通費・宿泊費**：本部の負担か加盟者の負担か。寮があるか
5. **研修中の収入と生活費**：研修期間中に支給があるか。1か月以上の研修なら、その間の生活費をどう用意するか
6. **研修費以外の指導料**：開業前後の指導料・開店支援費・営業支援費など、別の名目の費用がないか
7. **追加研修と再受講**：研修についていけなかったとき、スタッフが入れ替わったときの研修は有料か
8. **返還の条件**：研修を受けたあとに開業できなかった場合、研修費は返ってくるか（施行規則・ガイドラインとも「返還の有無」を挙げています）
9. **開業後の指導**：誰が、月に何回、どんな方法で指導するか（施行規則の「継続的な経営指導の方法及びその実施回数」）

研修費と並んで、毎月の支払いも確かめておきます。ロイヤリティの形と比べ方は[ロイヤリティの仕組みと比べ方](/guide/royalty/)、契約書の確認点は[フランチャイズ契約で確認すべきこと](/guide/contract/)にまとめています。

金額や条件は変わることがあります。気になる本部は、資料請求や説明会で最新の内容を確認してください。
