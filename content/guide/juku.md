学習塾は、教室1つから始められる業種です。この記事では、開業前に押さえておきたい「需要」「資格と届出」「法律のルール」「お金」を、公的機関の情報と各本部の公表値で整理します。

## 結論：学習塾開業の要点

- **開業に必要な資格・許認可はありません。** 個人なら税務署への開業届が基本です。ただし、期間2か月超・金額5万円超の契約は特定商取引法の「特定継続的役務提供」に当たり、書面の交付やクーリング・オフ、中途解約のルールを守る必要があります。
- **当サイトで開業資金を確認できた学習塾の本部8件では、約165万円から約897万円まで幅があります。** 物件取得費や内装費が含まれるかどうかも本部によって違います。
- **ロイヤリティは「授業料などの◯％」が中心です。** 掲載12本部のうち8本部が売上（授業料）に対する割合で、何に％がかかるか（月謝だけか、入会金も含むか）が本部ごとに違います。

## 学習塾の需要

文部科学省の「令和5年度 子供の学習費調査」によると、保護者が1年間に支出した学習塾費の平均は、公立中学校で230,385円、公立高等学校（全日制）で147,140円、公立小学校で75,194円でした。公立中学校では、学習塾費が私立中学校（168,058円）より多くなっています。

出典：[文部科学省「令和5年度子供の学習費調査」調査結果の概要（令和8年1月16日差替）](https://www.mext.go.jp/content/20260116-mxt_chousa01-000039333_3.pdf)

一方で、子どもの数は減り続けています。総務省統計局の人口推計では、2026年4月1日現在の15歳未満人口は1329万人で、45年連続の減少、総人口に占める割合は10.8％です。中小機構のJ-Net21も、学習塾の市場について「人口減少に歯止めのかからない現状から、近年縮小へと転じている」とし、生徒獲得競争は「さらなる激化が予想される」としています。

出典：[総務省統計局「我が国のこどもの数」（2026年5月4日）](https://www.stat.go.jp/data/jinsui/topics/topi1480.html)／[J-Net21「学習塾」（市場調査データ）](https://j-net21.smrj.go.jp/startup/research/service/cons-cramschool.html)

1人あたりの支出は大きい一方で、対象となる子どもは減っています。出店前に、教室を出す地域の子どもの数と、近くの塾の数を確かめておくことが欠かせません。

## 開業に資格は必要？必要な届出は？

中小機構のJ-Net21は、学習塾について「法的には学習塾を運営するにあたって資格、手続きは必要としない」と説明しています。そのうえで、関連する法律として特定商取引法を挙げています。

出典：[J-Net21「学習塾」](https://j-net21.smrj.go.jp/startup/guide/service/service08.html)

個人で始める場合は、税務署に開業届を出します。

| 届出 | 提出先 | 期限 |
|---|---|---|
| 個人事業の開業届出書 | 納税地を所轄する税務署 | 事業を始めた年分の確定申告期限まで |
| 青色申告承認申請書（青色申告をする場合） | 同上 | 年の途中で開業した場合は、開業日から2か月以内 |

出典：[国税庁「個人事業の開業届出・廃業届出等手続」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/04.htm)／[国税庁「所得税の青色申告承認申請手続」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/09.htm)

## 特定商取引法で守るべきルール

学習塾は、エステや結婚相手紹介サービスと同じく、特定商取引法の「特定継続的役務提供」の対象です。対象になるのは、入学試験に備えるため、または学校の補習のために、小学生から高校生などに教える契約のうち、**期間が2か月を超え、金額（入学金・受講料・教材費などの合計）が5万円を超えるもの**です。

| ルール | 内容 |
|---|---|
| 契約前・契約後の書面 | 契約の概要を書いた書面と、契約内容を明らかにした書面を渡す |
| クーリング・オフ | 法定の書面を受け取った日から8日以内なら、契約を解除できる |
| 中途解約の上限（授業開始前） | 請求できる損害賠償などは1万1,000円まで |
| 中途解約の上限（授業開始後） | 提供済みの授業の対価に、2万円または1か月分の授業料相当額のいずれか低い額を加えた額まで |

浪人生だけを対象にしたコースや、幼稚園・小学校の入学試験（いわゆる「お受験」）対策は対象外です。教室以外の場所で教える家庭教師は、別の上限額が決められています。

出典：[消費者庁 特定商取引法ガイド「特定継続的役務提供」](https://www.no-trouble.caa.go.jp/what/continuousservices/)

年間契約や講習のまとめ払いを用意する場合は、料金表と契約書を最初からこの上限に合わせておく必要があります。

## 2026年12月施行「こども性暴力防止法」と学習塾

子どもに接する仕事をする人の性犯罪歴を確認する仕組み（いわゆる日本版DBS）を定めた「こども性暴力防止法」が、2026年12月25日に施行されます。学校や認可保育所などには義務が課される一方、学習塾は**国の「認定」を受けた場合に対象となる仕組み**で、こども家庭庁は「認定申請は任意」としています。

学習塾が認定の対象となる「民間教育事業」には、次のような要件があります（こども家庭庁のQ&Aより）。

- 標準的な修業期間が半年以上で、その間に複数回教える
- 対面で指導する
- 子どもの自宅以外の、事業者が指定した場所で指導する
- 教える人が3人以上いる（雇用形態は問わない）

認定を受けた事業者は、従事者の性犯罪歴の確認（犯罪事実確認）、研修や相談体制づくり、確認した情報の適正な管理などを行います。認定事業者はマークを表示でき、認定申請は施行日の2026年12月25日から受け付けられます。

出典：[こども家庭庁「こども性暴力防止法」](https://www.cfa.go.jp/policies/child-safety/efforts/koseibouhou)／[こども家庭庁「こども性暴力防止法に関するQ＆A」（令和8年4月）](https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/80127231-8582-476e-a6e7-9347e725ed96/f490c24f/20260422_policies_child-safety_efforts_koseibouhou_49.pdf?v=20260423120419)／[こども家庭庁「こども性暴力防止法について」](https://www.cfa.go.jp/assets/contents/node/basic_page/field_ref_resources/80127231-8582-476e-a6e7-9347e725ed96/e131b83f/20251006_policies_child-safety_efforts_koseibouhou_08.pdf)

講師を雇って教室を運営する場合は、認定を受けるかどうか、フランチャイズなら本部としてどう対応するかを、加盟前に確認しておくとよいでしょう。

## ロイヤリティは「授業料の◯％」が中心

当サイトに掲載している学習塾の12本部を、ロイヤリティの形で分けると次のとおりです。

| ロイヤリティの形 | 本部数 |
|---|---|
| 売上（授業料など）に対する割合 | 8 |
| 生徒1人あたりの定額 | 1 |
| 売上ロイヤリティなし（と公表） | 1 |
| 公表値を確認できず | 2 |

割合制の本部でも、**何に％をかけるか**が違います。

| 本部 | ロイヤリティ（公表値） |
|---|---|
| トライプラス | 月謝の10％・季節講習の7〜10％。入会金や教材費にはかからない |
| 個別指導Axis | 入会金・授業料・施設関連諸費の10％。開校した月から1年間は生徒20名まで0円 |
| ECCベストワン | 入学金の50％、授業料諸費の10％（BMフランチャイズ掲載値） |
| フリーステップ | 税込授業料売上の10〜15％（BMフランチャイズ掲載値） |
| 個別指導WAM／セルモ | 売上の10％（BMフランチャイズ掲載値） |
| 学研CAIスクール | 生徒1人あたり 小学生1,397円、中学生2,882円（高校生は別途規定。BMフランチャイズ掲載値） |

割合制は、生徒が少ない開業直後は支払いも少なく済む一方、生徒が増えるほど支払いも増えます。生徒1人あたりの定額制は、授業料を高く設定しても支払いは変わりません。**想定する生徒数と授業料で、本部ごとの月の支払いを計算して比べる**のが確実です。

## 個人塾とフランチャイズ、どちらで始める？

| | 個人で独立 | フランチャイズに加盟 |
|---|---|---|
| 初期費用 | 物件・内装・備品・広告が中心 | 加盟金・研修費・システム費などが加わる |
| 毎月の支払い | なし | ロイヤリティ（授業料の割合が中心） |
| 教材・指導方法 | 自分で用意する | 本部の教材・学習システムを使える |
| 契約書・料金表 | 特定商取引法に沿って自分で整える | 本部のひな形があるか確認する |
| 集客 | 自分で集める | 本部のブランドや集客支援を使える |

J-Net21は、個人塾では経営者自身の「教育者」としての評価が事業の将来を左右すると説明しています。自分で教える力と地域での実績がある場合は個人で、教材や運営の仕組みを本部に頼りたい場合はフランチャイズで、という分け方が考えられます。

## 本部を選ぶときに確認したいこと

1. **開業資金に含まれるもの**：物件取得費・内装・広告費が入っているか、別途か
2. **ロイヤリティの対象**：月謝だけか、入会金・講習・教材にもかかるか。生徒数に応じた減免があるか
3. **契約書・料金表のひな形**：特定商取引法の書面・中途解約のルールに沿っているか
4. **講師の採用と安全対策**：講師募集の支援や、こども性暴力防止法への対応方針
5. **契約期間と解約の条件**：途中でやめるときの違約金の有無

金額や条件は変わることがあります。気になる本部は、資料請求や説明会で最新の内容を確認してください。
