フランチャイズ本部の店舗数について、多くの解説記事は「店舗数が多い本部はノウハウが蓄積されている」「急に増えている本部は注意」「直営店の比率を見る」といった見方を挙げています。この記事では、**本部が公表している店舗数の数字そのものが、どう書かれているか**を当サイトのデータで集計し、法令で決まっている店舗数の開示項目と照らして、確かめ方を整理します。本部を比べる順番や、財務書類・既存店の収支の見方は[フランチャイズ本部の選び方](/guide/erabikata/)で扱っています。

## 結論：店舗数を見るときの要点

- **基準日のない店舗数が多くあります。** 当サイトで店舗数の記載がある118本部のうち、いつ時点の数かが書かれていたのは17本部で、残る101本部には基準日の記載がありませんでした。基準日があっても、2021年度や2015年度の数字を載せている本部があります。
- **直営店を含むかどうかは、ほとんど書かれていません。** 直営と加盟の内訳を数か割合で示していたのは6本部（直営のみの2本部を含む）で、「加盟店の数」と明記していたのが8本部、「直営と加盟の合計」とわかるのが4本部でした。残る100本部は、どちらの数かが記載からはわかりません。
- **閉店・契約解除の数は、法定開示書面で確かめます。** 中小小売商業振興法の施行規則は、本部が契約前に渡す書面に、直近3事業年度の加盟者の店舗の数の推移として、年度末の店舗数・新規開店の数・解除された契約の数・更新された／更新されなかった契約の数を書くよう定めています。公表の「全国〇〇店舗」だけでは、この出入りはわかりません。

## 業界全体の規模

日本フランチャイズチェーン協会（JFA）の会長挨拶によると、「2024年度のJFAフランチャイズ統計調査では、我が国のフランチャイズ市場は、チェーン数1,291チェーン、店舗数約25万店、売上高約29兆円」で、いずれも前年を上回ったとしています。1チェーンあたりにならすと200店弱ですが、コンビニエンスストアのように1チェーンで数万店の本部も含まれるため、個々の本部の規模を見る物差しにはなりません。

## 法定開示書面に書かれる店舗数

### 施行規則が定める「加盟者の店舗の数の推移」

小売業のフランチャイズのうち中小小売商業振興法の対象となる本部（特定連鎖化事業を行う者）は、契約を結ぶ前に、事業の概要や契約の主な内容を書いた書面を渡して説明する義務があります。同法の施行規則第十一条は、この書面に少なくとも書くべき内容を表で定めており、店舗数については次のとおりです。

| 法が定める事項 | 施行規則が求める記載（原文） |
|---|---|
| 六　直近の三事業年度における加盟者の店舗の数の推移に関する事項 | イ　各事業年度の末日における加盟者の店舗の数 |
| | ロ　各事業年度内に新規に営業を開始した加盟者の店舗の数 |
| | ハ　各事業年度内に解除された契約に係る加盟者の店舗の数 |
| | ニ　各事業年度内に更新された契約に係る加盟者の店舗の数及び更新されなかつた契約に係る加盟者の店舗の数 |

ここで数えるのは「加盟者の店舗」です。本部が自分で運営する直営店の数は、この項目には入りません。また、同じ施行規則の第十条は、書面に書く事項として「当該特定連鎖化事業を行う者の当該事業の開始時期」や、加盟者の店舗の周辺で、同じか似た小売業の店を「自ら営業し又は当該加盟者以外の者に営業させる旨の規定の有無及びその内容」も挙げています。

出典：[e-Gov法令検索「中小小売商業振興法施行規則」（昭和四十八年通商産業省令第百号）第十条・第十一条](https://laws.e-gov.go.jp/law/348M50000400100)／[中小企業庁「特定連鎖化事業（フランチャイズ）について」](https://www.chusho.meti.go.jp/shogyo/shogyo/franchise.html)

### 推移の表から計算できること

イ〜ニの数がそろうと、公表の店舗数だけではわからない次の点を計算できます。

1. **純増の中身**：前年度末の店舗数＋新規開店（ロ）－解除（ハ）－非更新（ニの後半）で、今年度末の店舗数（イ）と合うかを見ます。店舗数が増えていても、新規開店が多く解除も多い本部と、解除がほとんどない本部とでは意味が違います。
2. **やめた店の割合**：解除と非更新の合計を、前年度末の店舗数で割ると、1年でやめた加盟店の割合の目安になります。
3. **更新の状況**：契約期間を満了した店のうち、更新した店と更新しなかった店の数がわかります。

この書面は契約前に交付されるものですが、日本フランチャイズチェーン協会は、各企業が提供した情報開示書面をウェブサイトの「情報開示書面」ページで、小売業・外食業・サービス業に分けて公開しています。同ページの利用上の注意は、「本データベースの情報は、原則として各企業が当該企業の責任において提供した情報開示書面をそのまま公表したものであり、」「経済産業省及び（一社）日本フランチャイズチェーン協会として記載内容に責任を持っておりません。」としています。候補の本部が掲載されていれば、資料請求の前に推移の表を見ることができます。

出典：[日本フランチャイズチェーン協会「情報開示書面」](https://www.jfa-fc.or.jp/particle/3614.html)

### 読むときに注意が要る書き方

- **「以上」「超」「約」「突破」の付いた数（16本部）**：らあめん花月嵐「国内外230店舗以上」、やきとり大吉「全国約500店舗」など。正確な数と基準日は資料で確かめます。らあめん花月嵐のように「国内外」とある場合は、海外の店を含みます。
- **出店準備中・開業予定を含む、または別に書く（4本部）**：SAKURA「準備中の店舗を含む」、SUMiTAS「出店準備中含む」、MANABASE（掲載6校＋開業予定）、睡眠改善鍼灸院NEL「0院（開院待機：6院）」。
- **累計の数（2本部）**：E部屋工房「2024年末累計数」、買取専門リサイクルマート「今までに500店舗以上」。累計には、すでに閉じた店も入ります。
- **グループ・複数ブランドの合計（4本部）**：ヒューマンアカデミーの2つの教室（「ヒューマンアカデミーFC全体」）、ばり嗎（3ブランド合計）、買取専門リサイクルマート（「グループ全国240店舗（総合リサイクルマート含む）」）。トータルリペア本部の4業態は、どれも同じ「全国加盟店総数1,076店」です。
- **同じ本部の公表の中で数が違う（6本部）**：買取専門店キングラムは本文が83店舗、同じページのフッターは「全国で95店舗」。だんらんの家はFCページ「全国１００社／３００店舗」、トップページ「全国200店舗展開中」など。
- **目標の数だけ、または数の記載なし（2本部）**：ASIESTA「目標は全国100店舗（現在数・時点記載なし）」、CodeCampKIDS（数の記載なし）。

## 店舗数について本部に確かめること

1. **基準日**：公表の店舗数は、いつ時点の数か。最新の数はいくつか
2. **直営と加盟の内訳**：直営店と加盟店がそれぞれ何店か。加盟店は何社（何人のオーナー）で運営しているか
3. **数えている範囲**：出店準備中・開業予定の店、海外の店、グループの別ブランドを含むか。累計か現在の数か
4. **直近3年の推移**：各年度末の加盟店の数、新規開店、契約解除、更新・非更新の数（施行規則第十一条の表「六」）
5. **やめた店の理由**：解除・非更新の店が、業績不振か、契約満了か、別の事情か
6. **近くの店舗**：出店予定地の周辺に、直営店や他の加盟店があるか、今後出す予定があるか（施行規則第十条の「自ら営業し又は当該加盟者以外の者に営業させる旨の規定」）
7. **事業を始めた時期**：フランチャイズ事業を始めてから何年か（施行規則第十条の「事業の開始時期」）

店舗数が少ない本部が悪い、多い本部がよいとは一概に言えません。店舗数とあわせて、加盟店の収支や本部の財務を見る方法は[フランチャイズ本部の選び方](/guide/erabikata/)、説明会での聞き方は[フランチャイズ説明会で聞くこと](/guide/setsumeikai/)、契約の解除・更新の条件は[フランチャイズ契約で確認すべきこと](/guide/contract/)にまとめています。

店舗数や条件は変わることがあります。気になる本部は、資料請求や説明会で最新の内容と、契約前の書面の内容を確認してください。
