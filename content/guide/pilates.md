ピラティスは、自宅やレンタルスペースで個人として始める方法から、テナントを借りて店舗を構える方法、フランチャイズに加盟する方法、いまある施設のメニューに加える方法まで、始め方の幅が広い業種です。この記事では、開業前に押さえておきたい「需要」「資格と届出」「会員との契約」「お金」を、公的機関の情報と、当サイトに掲載しているピラティスの本部のデータで整理します。

なお、当サイトに掲載しているピラティスの本部のうち「T-ÉLAN」は、当サイトの運営会社（株式会社mjo）が運営しています。

## 結論：ピラティス開業の要点

- **近い業種のヨガ教室・フィットネスクラブでは、インストラクターに資格保有の義務づけはありません（J-Net21）。** 税務署への開業届のほか、物件によっては防火管理者の選任など消防・自治体・保健所の手続きが関係します。
- **スポーツ庁の調査では、この1年に「エアロビクス・ヨガ・バレエ・ピラティス」を行った人は5.7％で、女性に限ると10.0％です。** 「今後始めてみたい」と答えた人は8.2％でした。
- **当サイトのピラティスの本部のロイヤリティは、「売上の割合に上限がつく」「売上の割合に最低額がつく」「ロイヤリティなし（月額サポート費）」の3つの形があります。** 同じ本部でもプランによって、加盟金と毎月の支払いのバランスが変わります。

## ピラティスの需要

スポーツ庁の「令和7年度 スポーツの実施状況等に関する世論調査」（18〜79歳の男女、WEBアンケート、有効回収数40,000件、2025年11月調査）では、この1年間に行った運動・スポーツとして「エアロビクス・ヨガ・バレエ・ピラティス」を挙げた人は次のとおりでした。

| | 令和7年度 | 令和6年度 |
|---|---|---|
| 全体 | 5.7％ | 6.3％ |
| 男性 | 1.4％ | 1.5％ |
| 女性 | 10.0％ | 11.0％ |

同じ調査で、今後始めてみたい運動・スポーツとして同じ種目を挙げた人は8.2％です。ピラティス単独の数字ではありませんが、行っている人は女性に大きく偏っていることがわかります。店舗の立地やメニューを考えるときは、主な利用者を誰と想定するかを先に決めておく必要があります。

出典：[スポーツ庁「令和7年度『スポーツの実施状況等に関する世論調査』の概要」](https://www.mext.go.jp/sports/content/260310-spt_kensport01-000048090_2.pdf)／[同 調査票・単純集計結果（PDF）](https://www.mext.go.jp/sports/content/260324-spt_kensport01-000048203_07.pdf)

## 開業に資格は必要？必要な届出は？

### インストラクターの資格

中小機構のJ-Net21は、ヨガ教室について「ヨガ教室のインストラクターには資格保有の義務付けはない」としています。フィットネスクラブのインストラクターについても、資格の保有は義務づけられていないとしています。ピラティスについてはJ-Net21に業種別の解説がありませんが、民間団体の認定資格が、指導の知識や技術を示す手段として使われています。フランチャイズに加盟する場合は、本部の研修や本部が指定する資格の取得が加盟の条件になっていることがあるため、資料請求や説明会で確認しておきます。

出典：[J-Net21「ヨガ教室」](https://j-net21.smrj.go.jp/startup/guide/service/2020021301.html)／[J-Net21「フィットネスクラブ」](https://j-net21.smrj.go.jp/startup/guide/service/06010.html)

### 物件と設備に関係する手続き

J-Net21は、ヨガ教室の開業に関係する法律と届出先として、消防法（所轄の消防署）、建築基準法・都市計画法（各自治体）、公衆浴場法・食品衛生法（保健所）を挙げています。どれが関係するかは、物件の用途や広さ、シャワーなどの設備や飲食の提供があるかで変わります。

出典：[J-Net21「ヨガ教室」](https://j-net21.smrj.go.jp/startup/guide/service/2020021301.html)

### 防火管理者の選任

東京消防庁によると、防火管理者が必要かどうかは建物全体の収容人員で決まります。店舗や飲食店などの特定用途を含む建物では「防火対象物全体の収容人員が30人以上のもの」が対象で、防火管理者が必要な建物では「建物所有者及びすべてのテナントで防火管理者の選任が必要」です。小さな区画を借りる場合でも、建物全体の条件によっては選任が必要になります。物件を契約する前に、所轄の消防署に確認しておくと確実です。

出典：[東京消防庁「防火管理者が必要な防火対象物と資格」](https://www.tfd.metro.tokyo.lg.jp/lfe/office_adv/jissen/p04.html)

あわせて、マシンを置く場合は搬入経路や床の強さ、レッスン中の音や振動について、契約前に貸主や管理会社と確認しておく必要があります。

## 会員との契約・解約のルールを先に決める

ピラティスは回数券や月額制のコースで会員と契約するのが一般的です。国民生活センターは2024年1月、スポーツジム等の契約トラブルについて注意を呼びかけています。全国の消費生活センターなどに寄せられた相談件数は次のとおりです。

| 年度 | 相談件数 |
|---|---|
| 2018年度 | 3,794件 |
| 2019年度 | 4,528件 |
| 2020年度 | 7,317件 |
| 2021年度 | 4,605件 |
| 2022年度 | 4,617件 |
| 2023年度（2023年12月31日までの登録分） | 3,796件（前年同期は3,249件） |

相談の特徴として、利用開始前なら無条件で解約できると考えていた、口頭で伝えただけで正式な解約手続きができておらず引き落としが続いた、体験・お試しプランのあとに通常プランへ自動で切り替わることを知らなかった、といったものが挙げられています。国民生活センターは消費者に対し、契約前に「解約時（休会時・退会時）の連絡先や精算方法、プランの期間等」や、体験・お試しプランの「自動更新の有無等」を確認するよう呼びかけています。

出典：[国民生活センター「スポーツジム等の契約トラブルにあわないために－契約・解約時に確認したいポイント－」（2024年1月24日）](https://www.kokusen.go.jp/news/data/n-20240124_2.html)／[同 公表資料（PDF）](https://www.kokusen.go.jp/pdf/n-20240124_2.pdf)

店舗を開く側としては、体験レッスンから入会への切り替わり方、休会・退会の受付方法と締め日、回数券の有効期限と返金方法を、契約書と説明の両方で示せるようにしておきたいところです。フランチャイズに加盟する場合は、本部が用意する会員規約がこれらをどう定めているかも確認しておきます。パーソナルトレーニングの契約トラブルの最新データは[パーソナルジムの開業ガイド](/guide/gym/)にまとめています。

## 毎月の費用・ロイヤリティ

当サイトのピラティスの本部では、ロイヤリティの形が本部やプランによって違います。

| 本部・プラン | ロイヤリティの形 | 掲載値 |
|---|---|---|
| T-ÉLAN（加盟店）Aプラン | 売上の割合＋上限 | 売上の8%・上限月10万円 |
| T-ÉLAN（加盟店）Bプラン | 売上の割合＋最低額 | 売上の12%・最低月10万円 |
| T-ÉLAN（導入パートナー） | ロイヤリティなし | 月額サポート費3万円／6万円／10万円の3プラン |
| SAKURA | 掲載値なし（公式の確認ができていない） | ― |

上限と最低額は、売上によって効き方が逆になります。

- **上限がつく場合（Aプラン）**：売上の8％が10万円に届くのは月の売上が125万円のときです。それより売上が多い月も、ロイヤリティは10万円で止まります。
- **最低額がつく場合（Bプラン）**：売上の12％が10万円を下回る月、つまり月の売上がおよそ83万円未満の月は、最低額の10万円を払います。

掲載値で計算すると、どの売上でも毎月のロイヤリティはBプランのほうがAプラン以上になり、その代わり加盟金はBプランのほうが100万円少なくなります。最初に多く払って毎月を抑えるか、最初を抑えて毎月多く払うかの違いなので、計画している売上と契約期間を当てはめて、総額で比べておくと選びやすくなります。

### 「フィットネス・美容・健康」の本部全体では

当サイトの「フィットネス・美容・健康」に掲載している15本部で見ると、ロイヤリティの形は、売上の割合が5本部、売上の割合と定額の組み合わせ（上限・最低保証・選択など）が4本部、定額が1本部、なしが1本部、掲載値なしが4本部です。開業資金を確認できた12本部では、40万円から2,000万円まで幅があり、中央値は440万円です（いずれも当サイトの掲載値、2026年11月10日時点）。

## 個人とフランチャイズ、どちらで始める？

| | 個人で開業 | フランチャイズに加盟 | 既存施設にメニュー追加 |
|---|---|---|---|
| 初期費用 | 物件・内装・マシンが中心 | 加盟金などが加わる | 物件・内装は既存のものを使う |
| 毎月の支払い | なし | ロイヤリティ | サポート費など（契約による） |
| レッスンの内容 | 自分でつくる | 本部のプログラムを使う | 提携先のプログラムを使う |
| 集客 | 自分で集める | 本部のブランドや集客の仕組みを使える | 既存の顧客に案内できる |
| 会員規約・料金 | 自分で決める | 本部の決まりに従う | 契約による |

指導の経験や顧客のあてがある場合は、個人で小さく始めて固定費を抑える選択肢があります。経験や集客の手段がない場合は、ロイヤリティを払ってでも本部のプログラムや研修を使う意味があります。すでにジムや整体院などを運営している場合は、店舗を新しく借りずにメニューとして加える方法も比べる対象になります（整体院の開業については[整体院の開業ガイド](/guide/seitai/)も参考にしてください）。

## 本部を選ぶときに確認したいこと

1. **レッスンの形**：マンツーマンか、少人数のグループか。マシンを使うか、マットで行うか。誰に向けた店舗か
2. **開業資金に含まれるもの**：物件取得費・内装・マシン・研修がどこまで入っているか。マシンは購入かリースか
3. **毎月の支払い**：ロイヤリティの計算方法、上限や最低額の有無、システム料・広告費などほかの支払い
4. **インストラクター**：オーナー自身が指導するのか、雇うのか。資格や研修の条件と、その費用
5. **会員規約**：体験からの切り替わり、休会・退会の手続き、回数券の期限と返金方法が決まっているか
6. **契約期間と解約の条件**：加盟契約の期間、自動更新の有無、途中でやめるときの違約金

金額や条件は変わることがあります。気になる本部は、資料請求や説明会で最新の内容を確認してください。
