パーソナルジムやフィットネスジムは、資格がなくても始められる業種です。ただ、出店が続いて競争が激しくなっており、小規模なジムの倒産も増えています。この記事では、開業前に押さえておきたい「市場」「資格と届出」「契約と解約のルール」「お金」を、公的機関の情報と、当サイトに掲載しているジム・フィットネスの本部のデータで整理します。

## 結論：ジム開業の要点

- **トレーナーにもジムの開業にも、必須の資格はありません。** ただし物件の用途や設備によって、消防署・自治体・保健所への手続きが関係します。
- **フィットネスクラブの倒産は2026年1〜8月で26件と過去最多ペースで、9割超が資本金1千万円未満の事業者です。** パーソナルトレーニングの契約トラブルの相談も、2025年度は1,457件に増えています。
- **当サイトで開業資金を確認できたジム系の4本部では、380万円から2,000万円〜まで幅があります。** ロイヤリティは、売上の割合が1本部、売上の割合に最低保証額がつくものが1本部、売上の割合と定額から選ぶものが1本部、掲載値なしが1本部です。

## ジム・フィットネスの市場

### 利用者の傾向

中小機構のJ-Net21が20代以上の男女1,000人に行った調査（2025年）では、フィットネスクラブを現在利用している人は11.3％で、61.0％は「一度も利用したことがない」と答えています。施設を選ぶ基準は「通いやすさ（立地やアクセス）」が45.9％で最も多く、「価格の安さ」の28.2％が続きます。

出典：[J-Net21「フィットネスクラブ（2025年版）」](https://j-net21.smrj.go.jp/report/research/service/cons-fitness2.html)

### 倒産は過去最多ペース

東京商工リサーチによると、フィットネスクラブの倒産（負債1,000万円以上）は2026年1〜8月で26件（前年同期比160.0％増）で、同期間として過去最多です。年間で最も多かったのは2023年の27件で、このペースが続けば年間でも上回るとしています。

26件のうち、資本金1千万円未満が24件（構成比92.3％）、従業員5人未満が23件（同88.4％）で、原因は「販売不振」が19件（同73.0％）と最も多くなっています。同社は、低資本で開業できるパーソナルジムでは、差別化のための「入会金無料」などのサービスコストが上がっていると指摘しています。

出典：[東京商工リサーチ「『フィットネスクラブ』の倒産が過去最多を更新へ　1-8月は26件、市場拡大もレッドオーシャンの兆し」（2026年9月7日）](https://www.tsr-net.co.jp/data/detail/1203212_1527.html)

## 開業に資格は必要？必要な届出は？

### 必須の資格はない

J-Net21は、パーソナルトレーナーについて「特別な資格は必要ない」とし、知識を証明する手段として健康運動指導士、JATI認定トレーニング指導者、NSCAのCSCS・NSCA-CPT、NESTA PFTなどの資格を挙げています。フィットネスクラブのインストラクターも、資格の保有は義務づけられていません。

出典：[J-Net21「パーソナルトレーナー」](https://j-net21.smrj.go.jp/startup/guide/service/2023061401.html)／[J-Net21「フィットネスクラブ」](https://j-net21.smrj.go.jp/startup/guide/service/06010.html)

### 物件と設備に関係する手続き

J-Net21は、フィットネスクラブの開業に関係する法律と届出先として、次の5つを挙げています。

| 法律 | 届出先 |
|---|---|
| 消防法 | 所轄の消防署 |
| 建築基準法 | 各自治体 |
| 都市計画法 | 各自治体 |
| 公衆浴場法 | 保健所 |
| 食品衛生法 | 保健所 |

どれが関係するかは、物件の用途や広さ、浴場・飲食の提供があるかで変わります。物件を契約する前に、出店先の自治体・消防署・保健所に確認しておく必要があります。

出典：[J-Net21「フィットネスクラブ」](https://j-net21.smrj.go.jp/startup/guide/service/06010.html)

### 個人で始めるときの税務の届出

| 届出 | 提出先 | 期限 |
|---|---|---|
| 個人事業の開業届出書 | 納税地を所轄する税務署 | 事業を始めた年分の確定申告期限まで |
| 青色申告承認申請書（青色申告をする場合） | 同上 | 年の途中で開業した場合は、開業日から2か月以内 |

出典：[国税庁「個人事業の開業届出・廃業届出等手続」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/04.htm)／[国税庁「所得税の青色申告承認申請手続」](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/09.htm)

## 会員との契約・解約のルールを先に決める

開業後の運営で見落とせないのが、会員との契約です。国民生活センターは2026年10月、パーソナルトレーニングの契約トラブルについて注意を呼びかけました。全国の消費生活センターなどに寄せられた相談は次のとおりです。

| 年度 | 相談件数 |
|---|---|
| 2021年度 | 495件 |
| 2022年度 | 722件 |
| 2023年度 | 861件 |
| 2024年度 | 885件 |
| 2025年度 | 1,457件 |
| 2026年度（8月31日まで） | 537件（前年同期は468件） |

契約購入金額は「10万円以上50万円未満」が43.2％で最も多く、50万円以上も11.6％あります。契約した人の85.2％は女性です。相談事例には、高額なコースや、痩身エステなどの関連サービスをあわせて勧められたもの、解約時に高額な解約料がかかると言われたものなどがあります。国民生活センターは消費者に対し、長期の契約では「途中でやめたらいくら返金されるのか」などを具体的に確認するよう呼びかけています。

出典：[国民生活センター「パーソナルトレーニングに関する契約トラブル－痩身エステ等、関連商品・サービスも勧誘されて高額に！？－」（2026年10月7日）](https://www.kokusen.go.jp/news/data/n-20261007_1.html)／[同 公表資料（PDF）](https://www.kokusen.go.jp/news/pdf/n-20261007_1.pdf)

ジムを開く側としては、コースの料金・期間・中途解約の返金方法を、契約書と説明の両方で示せるようにしておきたいところです。同じ資料では、関連サービスのうち特定商取引法の「特定継続的役務提供」に当たる契約（エステなど）はクーリング・オフの対象になる可能性があるとされています。フランチャイズに加盟する場合は、本部が用意する会員規約や勧誘の方法も確認しておきたい点です。

4本部のロイヤリティなどの掲載値は次のとおりです。

| 本部 | ロイヤリティ（掲載値） | 契約期間 | 店舗数（掲載値） |

| はじめての卓球 | 売上の7％（物販除く） | 3年 | 3店舗 |
| ZEAL BOXING FITNESS | 掲載値なし | 掲載値なし | 掲載値なし |
| chocoZAP | 売上の15%／月（最低保証額：16万5,000円／月・税込） | 7年 | 全国2,000店舗（2026年7月末時点、公式サイト） |

売上の割合が1本部、売上の割合に最低保証額がつくものが1本部、売上の割合と定額から選ぶものが1本部、掲載値なしが1本部です。

最低保証額がある場合、売上が少ない月でも最低保証額は払う必要があります。chocoZAPの場合、売上の15％が16万5,000円を下回る月、つまり月の売上が110万円未満の月は、最低保証額の16万5,000円（税込）を払う計算です。売上の割合と定額を選べる場合は、月の売上がいくらを超えると定額のほうが有利になるか（GENKEE倶楽部の掲載値なら、売上の10％が10万円を超える月の売上100万円が分かれ目）を、計画の売上と照らして確認しておくと選びやすくなります。

## 個人とフランチャイズ、どちらで始める？

| | 個人で開業 | フランチャイズに加盟 |
|---|---|---|
| 初期費用 | 物件・内装・マシンが中心 | 加盟金などが加わる |
| 毎月の支払い | なし | ロイヤリティ（売上の割合・最低保証額つき・定額など） |
| プログラム | 自分でつくる | 本部のプログラムやブランドを使える |
| 集客 | 自分で集める | 本部のブランドや集客の仕組みを使える |
| 会員規約・料金 | 自分で決める | 本部の決まりに従う |

J-Net21は、パーソナルトレーナーの仕事について「明確な料金基準がなく収入の個人差が大きい」ことや、「ダイエットなどの効果が表れない場合に責任を問われる」ことを特徴に挙げています。トレーニングの指導経験や顧客のあてがある場合は、個人で小さく始めて固定費を抑える選択肢があります。経験や集客の手段がない場合は、ロイヤリティを払ってでも本部のプログラムとブランドを使う意味があります。

出典：[J-Net21「パーソナルトレーナー」](https://j-net21.smrj.go.jp/startup/guide/service/2023061401.html)

## 本部を選ぶときに確認したいこと

1. **業態と対象の会員**：パーソナル指導か、セルフ利用か、スクール形式か。誰に向けたジムか
2. **開業資金に含まれるもの**：物件取得費・内装・マシン・研修がどこまで入っているか
3. **毎月の支払い**：ロイヤリティの計算方法、最低保証額の有無、システム料・広告分担金
4. **人員**：オーナー自身が指導するのか、トレーナーを雇うのか。採用と研修を本部がどこまで支援するか
5. **会員規約**：料金・契約期間・中途解約の返金方法が、わかりやすく決まっているか
6. **契約期間と解約の条件**：加盟契約の期間、更新料、途中でやめるときの違約金

金額や条件は変わることがあります。気になる本部は、資料請求や説明会で最新の内容を確認してください。
