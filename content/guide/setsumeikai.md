フランチャイズの説明会や個別相談会について、多くの解説記事は「参加するメリット」「先輩オーナーの話を聞く」「売上予測の根拠を確かめる」などを挙げています。この記事では、**説明会の前に公開情報で何がわかり、何が空欄のまま残るのか**を当サイトのデータで示し、そのうえで公正取引委員会のガイドラインに沿って、説明会で聞くことを整理します。契約書の条項の読み方は[フランチャイズ契約で確認すべきこと](/guide/contract/)、本部の財務や加盟店数の推移の見方は[フランチャイズ本部の選び方](/guide/erabikata/)で扱っています。

## 結論：説明会で聞くことの要点

- **公開情報だけでは埋まらない項目が多くあります。** 当サイト掲載152本部のうち、ロイヤリティを確認できなかった本部は39、契約期間は38、加盟金の金額は79本部でした。開業資金がわかる117本部でも、加盟金・ロイヤリティ・契約期間の3つがすべてそろうのは39本部です。
- **聞く項目は、公正取引委員会のガイドラインが示す8項目を軸にすると漏れにくくなります。** 商品の供給条件、指導の内容と費用、加盟時の金銭と返還、ロイヤリティの額と算定方法、決済と融資、損失の補償と経営支援、契約期間・更新・解除・中途解約、近くへの出店（ドミナント出店）の8つです。
- **公表値がある項目も、税区分・含まれるもの・条件を聞き直します。** 開業資金の公表値に税込・税抜の別が書かれていたのは117本部中25本部でした。開業資金・加盟金・ロイヤリティなどの金額を「先着」「期間限定」などの条件付きで下げている本部も11ありました。

## 説明会の前に：公開情報で表を作り、空欄を洗い出す

説明会では限られた時間で話を聞くことになります。先に本部の公表値を同じ項目で並べておくと、その場で何を聞くべきかがはっきりします。

当サイトに掲載している152本部について、項目ごとに公表値を確認できた本部の数を数えると、次のようになりました（2026年11月19日時点、data/brands.json を集計。各本部の確認日は2026年10月20日前後）。

| 項目 | 公表値を確認できた本部 | 確認できなかった本部 |
|---|---|---|
| 店舗数 | 118 | 34 |
| 開業資金（金額） | 117 | 35 |
| 契約期間 | 114 | 38 |
| ロイヤリティ（形・金額） | 113 | 39 |
| 自己資金の目安 | 95 | 57 |
| 加盟金（金額） | 73 | 79 |
| 募集エリア | 46 | 106 |
| 研修費 | 34 | 118 |
| 保証金 | 23 | 129 |

「確認できなかった」は、本部の公式ページや掲載媒体に記載が見つからなかったという意味で、その費用がかからないという意味ではありません。研修費や保証金は、開業資金の合計に含めて書かれている場合もあります。

ここから言えることは次の3つです。

- **お金の大枠（開業資金）は出ていても、毎月の支払いと契約の条件が欠けている本部が多い。** 開業資金がわかる117本部のうち、加盟金の金額がわからない本部が57、ロイヤリティがわからない本部が30、契約期間がわからない本部が27ありました。3つがすべてわかるのは39本部です。
- **ロイヤリティは「形」だけ書かれて金額がない場合がある。** 「固定型ロイヤリティ（金額記載なし）」「ロイヤリティーは定額で安心（金額記載なし）」のように、定額であることだけを示している本部が4つありました。
- **契約期間は書かれていても、やめるときの条件はほとんど書かれていない。** 契約期間を確認できた114本部のうち、更新に触れていたのは29本部、中途解約の条件に触れていたのは1本部でした。

### 空欄が残る本部を、同じ表で並べた例

開業資金はわかる一方で、ロイヤリティや契約期間が「—」になっている本部と、項目がそろっている本部を並べると次のようになります。「—」の欄が、説明会でまず聞く項目です。

買取専門店キングラムは「固定型ロイヤリティ」、やきとり大吉は「ロイヤリティーは定額」、魔法のパンケーキは「定額」と公表していますが、金額は確認できなかったため表では「—」としています。個太郎塾は開業資金の概算（Aタイプ6,925千円、税抜）に加えて、「別途250～300万円（6ヶ月分程度）の運転資金」を示しています。

## 説明会で聞くこと：公正取引委員会の8項目に沿って

公正取引委員会の「フランチャイズ・システムに関する独占禁止法上の考え方」（フランチャイズ・ガイドライン、改正：令和3年4月28日）は、本部の加盟者募集について「加盟希望者の適正な判断に資するため，十分な情報が開示されていることが望ましい」とし、開示が望ましい重要な事項として次の8つを挙げています。同時に、「加盟希望者側でも当該フランチャイズ・システムの事業内容について自主的に十分検討を行う必要があることはいうまでもない」としています。

| ガイドラインの項目（原文） | 説明会での聞き方の例 |
|---|---|
| 加盟後の商品等の供給条件に関する事項（仕入先の推奨制度等） | 本部やその指定先から仕入れる必要がある商品・資材はどれか。自分で選んだ仕入先を使えるか |
| 加盟者に対する事業活動上の指導の内容，方法，回数，費用負担に関する事項 | 開業前の研修は何日・どこで・いくらか。開業後は誰が、月に何回、どんな方法で指導に来るか。その費用は別にかかるか |
| 加盟に際して徴収する金銭の性質，金額，その返還の有無及び返還の条件 | 加盟金・保証金・研修費などは、それぞれ何の対価か。開業できなかったとき、途中でやめたときに返ってくるか |
| ロイヤルティの額，算定方法，徴収の時期，徴収の方法 | 売上の割合か定額か。割合なら何の売上が基準か。最低額はあるか。毎月いつ、どう払うか |
| 本部と加盟者の間の決済方法の仕組み・条件，本部による加盟者への融資の利率等に関する事項 | 売上金をいったん本部に送る仕組みか。本部が融資や分割払いをする場合の利率と条件 |
| 事業活動上の損失に対する補償の有無及びその内容並びに経営不振となった場合の本部による経営支援の有無及びその内容 | 売上が見込みを下回ったときに、本部の支援や補償はあるか。その中身は契約書に書かれているか |
| 契約の期間並びに契約の更新，解除及び中途解約の条件・手続に関する事項 | 契約は何年か。更新の条件と更新料。途中でやめるときの手続きと違約金の額 |
| ドミナント出店ができるか否かに関する契約上の条項の有無及びその内容並びにこのような営業が実施される計画の有無及びその内容 | 自分の店の近くに、本部や別の加盟店が出店できる契約か。いまその計画はあるか |

中途解約については、条件が不明確だと「解約が事実上困難となる」ことから、本部は中途解約の条件を契約上明確にし、「加盟者募集時に十分説明することが望ましい」とされています。近くへの出店について「配慮を行う旨」を示す場合も、「配慮の内容を具体的に明らかにした上で取決めに至るよう」留意が必要とされています。説明会で「近くには出しません」「途中でやめられます」と言われたら、それが契約書のどこに書かれているかを聞きます。

ガイドラインはまた、本部は契約締結について加盟希望者が十分に検討できるよう、必要な期間を置いて重要な事項を書いた書面を交付し、説明することが望ましいとしています。口頭の説明は、あとで書面で受け取れるかを確認します。

出典：[公正取引委員会「フランチャイズ・システムに関する独占禁止法上の考え方」（改正：令和3年4月28日）](https://www.jftc.go.jp/dk/guideline/unyoukijun/franchise.html)

当サイトのデータに当てはめると、ロイヤリティ（39本部）、契約期間（38本部）、加盟金（79本部）が空欄になりやすい項目でした。いずれもこの8項目に入っています。説明会では、表の「—」の欄をこの8項目の聞き方で埋めていくと、本部どうしを同じ項目で比べられるようになります。

## 公表値がある項目も、聞き直すこと

金額が公表されていても、そのまま比べられるとは限りません。当サイトのデータで見ると、次の3点は説明会で確かめておく必要があります。

### 税込か税抜か

開業資金を金額で確認できた117本部のうち、公表値に税込・税抜の別が書かれていたのは25本部でした。加盟金の金額がわかる73本部では19本部、定額や定額を含むロイヤリティの46本部では13本部です。開業資金が数百万円になると、税込か税抜かで差が大きくなります。比べる本部はすべて同じ税区分にそろえて聞きます。

### 開業資金に何が含まれるか

同じ「開業資金」でも、含まれるものは本部ごとに違います。例えば、おそうじ本舗の3,918,000円（税抜）は加盟金・開業サポート費・初期研修開業準備費・初期セットなどの合計で、まねきやの1,190万円（税別）は「物件取得費除く」とされています。物件取得費・内装・車両・研修費・運転資金のどこまでが入っているかを、項目ごとに聞きます（[開業資金と融資](/guide/funding/)）。

### 「0円」「割引」の条件

開業資金・加盟金・申込金・ロイヤリティの公表値に「先着」「限定」「キャンペーン」「減額」などの条件が付いていた本部が11ありました（2026年10月20日の確認時点）。例えば、次のような書き方です。

- ミス・シャーロック：「先着10店舗に限り加盟料2,200,000円→1,500,000円」
- 移動スーパーはじ丸：「加盟金0円で開業可能（通常 100 万円のところ、キャンペーン中につき 0 円）」
- 今すぐ喪服：ロイヤリティ「1次募集限定10社のみ1年間0円 1年以降月額3万円（税別）」（BMフランチャイズ掲載値）

条件付きの金額は、自分が説明会に行く時点でも適用されるか、期間が過ぎたあとの金額はいくらかを聞きます。ロイヤリティが「なし」でも、月会費やシステム利用料を別に定めている本部があります（[ロイヤリティの仕組みと比べ方](/guide/royalty/)）。

## 売上の見込みを示されたら

説明会では、モデル収益や収益シミュレーションが示されることがあります。公正取引委員会のガイドラインは、予想売上や予想収益を示す場合は「類似した環境にある既存店舗の実績等根拠ある事実，合理的な算定方法等に基づくことが必要」としています。どの店舗の、いつの実績から出した数字かを聞きます。聞き方の詳細は[フランチャイズ本部の選び方](/guide/erabikata/)のステップ3にまとめています。

出典：[公正取引委員会「フランチャイズ・システムに関する独占禁止法上の考え方」](https://www.jftc.go.jp/dk/guideline/unyoukijun/franchise.html)

## 説明会のあとにすること

### 既存の加盟店で話を聞く

中小機構のJ-Net21は、良い本部と悪い本部の見分け方として、サポート体制について「本部に事前に確認するほかに、すでに加盟しているオーナーを数軒訪問して、評価を聞いてみた方がよいでしょう」としています。説明会で紹介されたオーナーだけでなく、自分で選んだ店舗にも行けるかを本部に聞いておくと、比べる材料が増えます。

出典：[J-Net21「良いFC（フランチャイズチェーン）と悪いFCの見分け方のポイントを教えてください。」](https://j-net21.smrj.go.jp/qa/development/Q0371.html)

### 書面で受け取り、その場では契約しない

小売業のフランチャイズのうち中小小売商業振興法の対象となる本部は、契約前に事業の概要や契約の主な内容を書面で交付し、説明する義務があります。説明会の場で書類への記入を求められたときの考え方や、日本フランチャイズチェーン協会の熟考期間（7日以上）については、[フランチャイズ契約で確認すべきこと](/guide/contract/)にまとめています。

出典：[中小企業庁「特定連鎖化事業（フランチャイズ）について」](https://www.chusho.meti.go.jp/shogyo/shogyo/franchise.html)

## 説明会に持っていくチェックリスト

1. 候補の本部の開業資金・加盟金・ロイヤリティ・契約期間を、同じ表に並べたか（空欄＝聞く項目）
2. 金額はすべて税込か税抜かをそろえたか
3. 開業資金に、物件取得費・内装・車両・研修費・運転資金のどこまでが含まれるか聞いたか
4. ロイヤリティの額と算定の基準、最低額、ロイヤリティ以外の月額を聞いたか
5. 加盟金・保証金が返ってくる条件を聞いたか
6. 契約期間、更新の条件と更新料、中途解約の手続きと違約金を聞いたか
7. 近くへの出店の可否と計画、研修と開業後の指導の回数・費用を聞いたか
8. 「先着」「期間限定」の金額は、自分にも適用されるか、期間後はいくらかを聞いたか
9. 口頭で聞いた内容を、書面で受け取れるか確認したか

金額や条件は変わることがあります。気になる本部は、資料請求や説明会で最新の内容を確認してください。
