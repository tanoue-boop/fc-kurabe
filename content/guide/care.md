介護の仕事で独立する方法には、デイサービス（通所介護）のように介護保険の指定を受けて営業する形と、訪問マッサージのように医療保険の療養費を使う形、保険を使わない生活支援サービスの形があります。どの形かで、必要な資格や手続き、お金の入り方が変わります。この記事では、開業前に押さえておきたい「市場」「指定と基準」「入金の流れ」「お金」を、公的機関の情報と、当サイトに掲載している介護・福祉の本部のデータで整理します。

## 結論：介護フランチャイズ・デイサービス開業の要点

- **デイサービスは法人でないと指定を受けられないのが原則です。** 自治体との事前協議、人員と設備の基準を満たしたうえでの指定申請が必要で、定員18名以下の小規模なデイサービスは市町村が指定します。
- **介護報酬は、サービスを提供した月の翌月10日までに請求し、支払いの通知は翌々月に届きます。** 開業してしばらくは、入金より先に人件費や家賃が出ていく前提で運転資金を用意する必要があります。
- **当サイトで開業資金を確認できた介護・福祉系の3本部では、100万円から2,950万円まで幅があります。** ロイヤリティは、売上の割合が1本部、定額が1本部、掲載値なしが1本部です。

## デイサービスを開くときの法人格と指定

### 法人であることが前提

大阪市の「新規介護保険事業者の指定前の確認について（Q&A）」は、「申請者は法人である必要がある」としています。個人で始める場合も、まず株式会社や合同会社などの法人をつくることになります。名古屋市も「申請者が法人であること（一定条件のもと、個人での開設も可）」としており、例外の扱いは自治体に確認が必要です。

出典：[大阪市「新規介護保険事業者の指定前の確認について（Q&A）」](https://www.city.osaka.lg.jp/fukushi/cmsfiles/contents/0000280/280121/siteimaeQA.pdf)／[名古屋市「介護保険事業者の指定について」（令和5年10月31日）](https://www.kaigo-wel.city.nagoya.jp/view/kaigo/company/docs/2023110200014/files/4-1_designation.pdf)

### 事前協議と指定申請

大阪市は、通所介護や地域密着型サービスは「事前協議が必要です」としています。名古屋市では、申請の1回目の提出は指定を受けたい日の「2か月前の10日必着」で、指定の有効期限は6年です。物件を契約する前に、出店先の自治体の手引きでスケジュールを確認しておく必要があります。

出典：[大阪市「新規介護保険事業者の指定前の確認について（Q&A）」](https://www.city.osaka.lg.jp/fukushi/cmsfiles/contents/0000280/280121/siteimaeQA.pdf)／[名古屋市「介護保険事業者の指定について」](https://www.kaigo-wel.city.nagoya.jp/view/kaigo/company/docs/2023110200014/files/4-1_designation.pdf)

### 定員18名以下は市町村が指定する

横浜市は、地域密着型通所介護を「定員が18名以下の小規模なデイサービス」とし、事業者の指定は市町村が行うこと、原則として「指定をした市町村の被保険者のみが利用できます」と案内しています。定員19名以上の通所介護とは、申請先も利用できる人の範囲も違います。

出典：[横浜市「地域密着型サービス（全般）」](https://www.city.yokohama.lg.jp/business/bunyabetsu/fukushi-kaigo/kaigo/shinsei/service/micchaku/zenpan.html)

## 人員と設備の基準

東京都の指導検査基準から、通所介護の主な基準をまとめると次のとおりです。

| 項目 | 基準（東京都の指導検査基準による） |
|---|---|
| 管理者 | 常勤で、原則として事業所の管理に専ら従事する（管理上支障がなければ他の職務も可） |
| 生活相談員 | 提供日ごとに、提供時間数に応じて1以上を配置 |
| 看護職員 | 1以上（病院・診療所・訪問看護ステーションとの連携による確保も可） |
| 介護職員 | 利用者15人までは1以上、15人を超える場合は人数に応じて加える |
| 機能訓練指導員 | 1人以上 |
| 常勤要件 | 生活相談員または介護職員のうち1人以上は常勤 |
| 食堂と機能訓練室 | 合計面積が「3平方メートルに利用定員を乗じて得た面積以上」 |

例えば定員20名なら、食堂と機能訓練室だけで合計60㎡以上が必要です。物件の広さは、定員と売上の見込みに直結します。

出典：[東京都福祉局「指導検査基準（通所介護）」（令和6年度）](https://www.fukushi.metro.tokyo.lg.jp/documents/d/fukushi/R6tusho)

## 介護報酬が入金されるまでの流れ

介護保険のサービスは、利用者の自己負担分を除く介護報酬が後から入金されます。京都府国民健康保険団体連合会の案内では、流れは次のとおりです。

| 時期 | 内容 |
|---|---|
| サービス提供月 | 利用者にサービスを提供（利用者からは自己負担分を受け取る） |
| 翌月10日まで | 国保連合会に請求明細書などを提出 |
| 翌月の月末営業日 | 返戻（差し戻し）などの審査結果の通知 |
| 翌々月 | 支払通知の送付（伝送請求の事業所は翌々月14日）。その後、指定口座に振り込まれる |

開業した月の介護報酬の支払通知が届くのは翌々月で、書類に不備があって差し戻されれば、さらに遅れます。その間も人件費や家賃は毎月かかるため、開業資金とは別に、数か月分の運転資金を見込んでおく必要があります。

出典：[京都府国民健康保険団体連合会「介護保険給付費等の請求について」](https://www.pref.kyoto.jp/kaigo/documents/kokuhorenn.pdf)

## 訪問マッサージを開くときの免許と届出

当サイトの「介護・福祉」には、在宅の高齢者を訪問するマッサージの本部も含まれています。マッサージを業として行うには、あん摩マッサージ指圧師の免許が必要です。施術所を持たずに出張だけで施術する場合も、文京区は「出張施術業務を開始した場合、開始後10日以内に保健所に届出が必要」としています。

健康保険の療養費の対象になるのは、全国健康保険協会（協会けんぽ）によると「筋麻痺・関節拘縮等の症状が認められ」「施術が必要と医師が同意している場合に限ります」。継続して保険を使うには6か月ごとに文書による同意が必要で、オンライン診療による医師の同意書は認められません。

出典：[文京区「あん摩マッサージ指圧師、はり師、きゅう師の出張業務開始・廃止届」](https://www.city.bunkyo.lg.jp/b026/p002943.html)／[全国健康保険協会「はり・きゅう、あん摩・マッサージを受けたとき」](https://www.kyoukaikenpo.or.jp/benefit/acupuncture_and_moxibustion/)

## 毎月の費用・ロイヤリティ

3本部のロイヤリティなどの掲載値は次のとおりです。

| 本部 | ロイヤリティ（掲載値） | 契約期間 | 店舗数（掲載値） |
|---|---|---|---|
| フレアス在宅マッサージ | 売上に対して13.5％～18.5％ | 5年 | 429（2025年7月現在） |
| くらしのサポート サポっ人 | 11,000円～ | 1年間の自動更新 | 掲載値なし |
| ソレイルミナーレ | 掲載値なし | 掲載値なし | 28 |

売上の割合が1本部、定額が1本部、掲載値なしが1本部です。売上の割合で払う形は売上に応じて支払いが増え、定額は売上が少ない月も同じ額がかかります。くらしのサポート サポっ人の「11,000円～」は、支払いの単位（月額かどうか）が掲載値からは読み取れないため、資料で確認してください。

デイサービスの場合、売上の多くは介護報酬です。ロイヤリティが売上の割合で決まる契約では、介護報酬の入金が翌々月になることと、ロイヤリティの支払い時期の関係も確認しておきたい点です。

## 個人とフランチャイズ、どちらで始める？

| | 自分で開業 | フランチャイズに加盟 |
|---|---|---|
| 初期費用 | 法人設立・物件・改修工事が中心 | 加盟金などが加わる |
| 毎月の支払い | なし | ロイヤリティ（売上の割合・定額など） |
| 指定申請・運営 | 自治体の手引きを読み、自分で書類をそろえる | 本部の支援を受けられる場合がある |
| サービス内容 | 自分で決める | 本部のプログラムや運営の仕組みを使う |

デイサービスの指定基準は、フランチャイズでも自分で開業しても同じです。フランチャイズに加盟すると、本部のプログラムや運営の仕組みを使える一方、ロイヤリティなどの支払いが契約期間中続きます。指定申請の書類づくりや、人員の採用をどこまで本部が支援するかは、本部ごとに違います。

## 本部を選ぶときに確認したいこと

1. **事業の形**：介護保険の指定を受ける事業か、医療保険の療養費を使う事業か、保険を使わない事業か
2. **必要な資格と人員**：あん摩マッサージ指圧師などの免許が要るか、生活相談員・看護職員・機能訓練指導員を誰がどう確保するか
3. **指定申請の支援**：法人設立、自治体との事前協議、申請書類の作成を本部がどこまで支援するか
4. **開業資金に含まれるもの**：物件取得費・改修工事・送迎車両・機器がどこまで入っているか
5. **運転資金**：介護報酬の入金が翌々月になることを踏まえ、何か月分の運転資金を見込んでいるか
6. **毎月の支払いと契約期間**：ロイヤリティの計算方法と支払い時期、更新料や途中でやめるときの違約金

金額や条件は変わることがあります。気になる本部は、資料請求や説明会で最新の内容を確認してください。
